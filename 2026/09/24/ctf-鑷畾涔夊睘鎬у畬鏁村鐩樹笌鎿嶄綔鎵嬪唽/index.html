零基础详解版 —— 每一步都讲清「作用 · 原理 · 为什么这么做」

平台：ctf.bi6pcr.com | 题目：自定义属性（60 分 · Web / 基础）

一、题目回顾

题目描述：页面上有一个看起来空空的元素。审查元素，看它的 data-flag 属性。查看源代码也能看到。

题目提示：右键这个盒子 → 检查。

一句话思路：

flag 被写在某个 HTML 元素的 data-flag 自定义属性里。元素“看起来是空的”，但它的属性里有数据。用“审查元素”或“查看源代码”就能看到 data-flag 的值。

结果：元素的 data-flag 属性值即 flag。

说明：flag 在你的实例页面里，需要你自己查看获取；本手册把方法与原理讲透。

二、前置概念：HTML 属性 与 data-* 自定义属性

2.1 什么是 HTML 属性

HTML 元素可以带“属性”，写在标签的尖括号里，用来描述这个元素，比如：

其中 class、id 就是属性。

2.2 什么是 data-* 自定义属性

HTML5 允许开发者自定义以 data- 开头的属性，专门用来“存一点额外数据”：

标签之间是空的（页面上什么都不显示），但它的 data-flag 属性里装着 flag。这类属性不会显示在页面上，必须“审查元素”或“看源码”才能发现。

2.3 审查元素 vs 查看源代码（重要区别）

方式 看的是什么 怎么打开
审查元素（Inspect） 浏览器运行后的“实时 DOM”（JS 改过也算） 右键元素 → 检查；或 F12 → Elements
查看源代码 服务器发来的“原始 HTML” Ctrl+U

本题两者都能看到 data-flag（提示说“查看源代码也能看到”）。遇到别的题时，若一个看不到就换另一个。

三、完整操作步骤（Step by Step）

Step 0 开实例并打开页面

wsrx connect ‘把那条 wss://… 粘到这里’

浏览器打开它映射出来的 http://127.0.0.1:端口

Step 1（推荐）右键“空盒子” → 检查

  • 在那个看起来空空的元素上右键 → 选“检查 / Inspect”；
  • 开发者工具 Elements（元素）面板会定位到那个元素；
  • 展开它的标签，看属性，找到 data-flag=”CTF{…}” —— 引号里的就是 flag。

Step 2 查看网页源代码

Ctrl+U 打开网页源代码
Ctrl+F 搜索 data-flag （或搜 flag{ / CTF{）

Step 3 命令行方式

curl http://127.0.0.1:端口/

作用：把服务器返回的 HTML 打印出来；在输出里找 data-flag=”CTF{…}”。

四、原理详解：元素“空”为什么还有数据

元素的“内容”和“属性”是两回事：

# 属性写在这里（flag 在属性里）
# 内容区是空的（页面上看着空）

浏览器只把“内容区”渲染出来给人看，属性是给程序/脚本看的，所以页面上看着是空的，但属性里可能藏着数据。这就是本类题目“藏在属性/注释里”的套路。

五、易错点

现象 / 报错 原因 解决
审查元素看不到 data-flag 元素是 JS 动态生成的 / 看错元素 改用 Ctrl+U 看源代码搜 data-flag；或 F12 里按 Ctrl+F 在 DOM 里搜
页面里找不到“盒子” 元素不可见或极小 右键页面空白处 → 检查；或直接在源代码里搜 data-flag
提交说错误 复制带了引号或空格 只复制 data-flag=”…” 引号里的值
想搜 flag 却搜不到 大小写/写法不同 分别搜 data-flag、flag{、CTF{
页面打不开 实例过期 / 端口变了 重开实例、重连 wsrx，用新端口

六、速查卡

一句话记法：右键盒子→检查，看 data-flag；或 Ctrl+U 搜 data-flag。

浏览器：

右键元素 -> 检查 -> Elements 里看 data-flag=”…”
Ctrl+U -> Ctrl+F -> 搜 data-flag

命令行：

curl http://127.0.0.1:端口/

附录：HTML 里常见的“藏数据”位置（Web 拓展）

藏在哪里 怎么看
HTML 注释 Ctrl+U 搜 flag；右键检查
元素属性 data-*（本题） 审查元素 / 查看源代码
隐藏元素（display:none、type=hidden） 审查元素，或搜 input
元素的其他属性（alt、value、title） 右键检查逐个看
页面里被注释掉的代码 Ctrl+U 看源码
JS 文件 / 接口返回 F12→源代码 / 网络

思路：Web 基础题 = “把页面的每个角落看一遍”：正文、源码、注释、属性、存储、请求头、接口。
