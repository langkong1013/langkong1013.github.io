【杂】花椰菜密语（Crypto Caulingo）

langkong10132026-09-242026-10-28

零基础详解版 —— 每条命令/每行代码都讲清「作用 · 原理 · 为什么这么做」

平台：ctf.bi6pcr.com | 题目：花椰菜密语（500 分 · 杂项 / Crypto）

一、题目回顾

题目背景：一个关于“花椰菜”的剧情 PDF（project_dc.pdf），里面藏着一条关键的数学约束。

真正用来解题的数据在附件 msg.txt 里，给出三样东西：

n = 279833462431005435913671…（一个约 617 位的大整数）
e = 65537
c = 5ac3f5bd2f3f2c34c6bcca…（十六进制）

PDF 里的约束：|A × P − B × Q| < 10000 ，且 1 ≤ A,B ≤ 1000

（本题改编自 Google CTF 2019 Beginners Quest《Crypto Caulingo》。）

一句话思路：

这是一道 RSA 题，但 N 的两个素因子 P、Q 之间藏着“弱点”：把它们分别乘上两个很小的整数 A、B 之后，会变得几乎相等（差 < 10000）。利用这个弱点，可以用 Fermat 因数分解把 N 拆开，再用常规 RSA 流程解密，得到 flag。

最终 flag：CTF{a4ef9fd20efff489d82ceb399e870995274a4c26}

二、前置概念：RSA 到底在干嘛（零基础）

RSA 是最常见的公钥加密。它用到这些量：

符号 含义
N 模数 = P × Q（P、Q 是两个很大的素数）
e 公钥指数（常见就是 65537）
c 密文 = 明文^e mod N
P、Q 两个大素因子，是必须保密的“钥匙”
φ(N) (P−1)×(Q−1)，欧拉函数
d 私钥指数 = e 在模 φ(N) 下的逆元

加密：c = mᵉ mod N　（m 是把 flag 当成一个大整数）

解密：m = c^d mod N　（只要知道 d 就能还原 m）

关键点：算 d 必须先知道 φ(N)=(P−1)(Q−1)，也就是必须先知道 P、Q。

RSA 的安全性，就建立在“给定 N，很难分解出 P、Q”上。所以破 RSA 的第一目标就是：分解 N。

三、本题的“后门”：因子被“小整数倍”拉近了

正常 RSA 里 P、Q 随便取，N 很难分解。但这题给了一条额外约束：

存在小整数 A、B（≤1000），使得 |A·P − B·Q| < 10000。

意思是：把 P 乘 A、Q 乘 B 之后，两个结果几乎相等（相差不到 1 万）。

于是构造：

M = A × B × N = (A·P) × (B·Q)

M 的两个因子 (A·P) 和 (B·Q) 非常接近。“两个因子很接近的合数”正是 Fermat 分解法最擅长处理的——它能一瞬间拆开。

拆开后，再 gcd(N, A·P) 就能还原出真正的 P（因为小整数 A 与素数 P 不可能有公因数）。

四、Fermat 因数分解原理（附手算演示）

4.1 原理

Fermat 的依据是一个恒等式：若 M = x·y，令 a=(x+y)/2、b=(x−y)/2，则 M = a² − b²。

反过来：从 a = ⌈√M⌉ 开始，看 a² − M 是不是完全平方数：

  • 若 a² − M = b²（是完全平方），那么 x = a − b，y = a + b，分解成功。
  • 若不是，就把 a 加 1 再试。

当 x 和 y 很接近时，a 只需加很少几次就能命中——所以“因子越接近，Fermat 越快”。

4.2 手算演示（小例子，感受一下）

设 M = 10403，我们猜它的两个因子很接近：

√10403 ≈ 101.99 → 从 a = 102 开始
a=102: a² − M = 10404 − 10403 = 1 = 1² → 命中！
b = 1
两个因子： a−b = 101 ，a+b = 103
验证： 101 × 103 = 10403 ✓

整个过程只试了一次就算出来了——这就是“因子接近”时 Fermat 的威力。

本题里 M = A·B·N 的两个因子 (A·P)、(B·Q) 相差不到 1 万，而 M 是个巨大的数，两者“相对差距”极小，所以 Fermat 只需极少数几步就能命中。

五、完整解题步骤（Step by Step）

Step 1 读数据

从 msg.txt 读入 N（十进制大整数）、e = 65537、c（十六进制要先转成整数）。

Step 2 暴力小乘数 A、B

A、B 都在 1~1000 之间，最多 100 万种组合。对每种组合计算 M = A×B×N。

Step 3 对每个 M 做 Fermat 分解

若某个 M 能被 Fermat 迅速拆成两个接近的因子，那两个因子就是 (x·P) 和 (y·Q)。

Step 4 用 gcd 还原真正的素因子 P

计算 P = gcd(N, 因子)。因为 A、B ≤ 1000 而 P 是巨大素数，gcd 会把 P 干净地“拎”出来。

本例命中：A=661、B=721（对应 721·P ≈ 661·Q，差值 3102）。

Step 5 常规 RSA 解密

有了 P、Q 就能算 φ(N)=(P−1)(Q−1)、私钥 d = e⁻¹ mod φ(N)，再 m = c^d mod N，把 m 转回字节即得明文。

Step 6 得到 flag

明文：Dear cauliflower brethren, the humans are still listening,
so keep flapping in code. The password to the leaf-network is
CTF{a4ef9fd20efff489d82ceb399e870995274a4c26} …

flag = CTF{a4ef9fd20efff489d82ceb399e870995274a4c26}

def fermat(M, limit=4): # Fermat 因数分解
a = math.isqrt(M) # 从 sqrt(M) 向上取整开始
if a * a < M:
a += 1
for _ in range(limit):
b2 = a * a - M
b = math.isqrt(b2)
if b * b == b2: # a^2 - M 是完全平方
return a - b, a + b # 两个因子
a += 1
return None

for A in range(1, 1001): # 暴力小乘数 A、B
for B in range(1, 1001):
r = fermat(A * B * N) # 对 M = ABN 做 Fermat 分解
if r:
P = math.gcd(N, r[0]) # gcd 还原出真正的素因子 P
if 1 < P < N:
Q = N // P
d = pow(e, -1, (P - 1) * (Q - 1)) # RSA 私钥指数
m = pow(c, d, N) # RSA 解密
print(“P =”, P); print(“Q =”, Q)
print(bytes.fromhex(format(m, “x”)))
raise SystemExit

七、脚本逐段讲解

代码 作用
math.isqrt(M) 对整数 M 求平方根（取整数部分）
a = ceil(sqrt(M)) Fermat 的起点：向上取整的平方根
b2 = a*a - M; b = isqrt(b2) 检验 a²−M 是否为完全平方数
if b*b == b2: return a-b, a+b 命中！返回两个接近的因子
fermat(ABN) 对 M=A·B·N 做 Fermat 分解（因子接近时极快）
math.gcd(N, r[0]) 从“A·P 或 B·Q”里用最大公约数还原出素因子 P
pow(e, -1, (P-1)*(Q-1)) 求私钥 d（e 的模逆元，Python 3.8+ 支持）
pow(c, d, N) RSA 解密，得到明文大整数 m
bytes.fromhex(format(m, “x”)) 把整数 m 转回原始字节（即 flag 文本）

八、易错点

现象 / 报错 原因 解决
程序跑很久没结果 乘数范围不够 / Fermat 步数太小 把 A、B 上限调到 1000；fermat 的 limit 适当加大
fermat 返回 None M 的因子还不够接近，limit 太小 增大 limit（如 50）或换组合继续找
gcd 得到 1 或 N 因子取错了（不是 A·P/B·Q） 换 fermat 返回的另一个因子，或继续找别的 A、B
c 当作十进制读 c 是十六进制 用 int(c_str, 16) 转换
明文是乱码 没有按字节还原 用 bytes.fromhex(format(m,”x”)) 转回字节
pow(e,-1,phi) 报错 Python 版本太老（<3.8） 改用 gmpy2.invert(e, phi) 或手写扩展欧几里得

九、速查卡

一句话记法：小乘数拉近因子 → Fermat 分解 A·B·N → gcd 还原 P → RSA 解密。

关键点 要点
弱点 存在小 A、B 使 |A·P − B·Q| < 10000
构造 M = A·B·N = (A·P)(B·Q)，两因子接近
分解 Fermat：从 ⌈√M⌉ 起找 a²−M 为完全平方
还原 P = gcd(N, 因子)（A 很小，不会污染 gcd）
解密 d = e⁻¹ mod (P−1)(Q−1)，m = c^d mod N
输出 bytes.fromhex(hex(m)) 得到 flag 文本

附录：本题相关背景

  • 原版 Google CTF 2019《Crypto Caulingo》同一思路：暴力小乘数 + Fermat 分解 + gcd。
  • 平台最初漏传了 msg.txt（只有剧情 PDF），补齐数据后按上面流程即解出。
  • 相近知识点：RSA 常见攻击——Fermat（因子接近）、小指数、共享素数（gcd）等。
