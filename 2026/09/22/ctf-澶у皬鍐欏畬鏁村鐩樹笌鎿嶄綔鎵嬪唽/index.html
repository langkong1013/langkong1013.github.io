【基础】大小写

langkong10132026-09-222026-10-28

—— 知识点详解 · 完整流程 · 脚本 · 易错点 · 速查

平台：ctf.bi6pcr.com（学校网络安全练习赛） | 题目：大小写（100 分）

一、题目回顾

题目描述：每个英文字母的大小写都换过了，再换一次即可。

页面给出的文本：

FLAG{CASE_66643E3F3CF9}

再切换一次大小写，得到 flag：

flag{case_66643e3f3cf9}

二、知识点详解：大小写切换

2.1 思路

题目说“大小写都换过了”，意思是每个字母被做了”大写↔小写”的互换。因为”互换”这个操作做两次就还原，所以只要对页面文本再做一次同样的互换，就得到正确文字。

2.2 什么是 swapcase（大小写互换）

把字符串里每个字母的大小写翻转：大写变大写、小写变小写；非字母字符（数字、{ } _ 等）不受影响。

原始 互换后
FLAG flag
CASE case
{ } _ 6 4 3 { } _ 6 4 3（不变）

2.3 两种常用做法

方法 命令
Python python3 -c “print(‘串’.swapcase())”
tr 命令 echo ‘串’ | tr ‘A-Za-z’ ‘a-zA-Z’

2.4 连接知识（网页类容器题）

curl / 浏览器 → http://127.0.0.1:本地端口 → wsrx（隧道） → wss://平台代理 → 容器网页

三、完整操作步骤（Step by Step）

Step 1 创建实例、复制地址

点【创建实例】，等“运行中”，复制 wss://… 地址。

Step 2 启动隧道（终端 1，保持运行）

cd ~
./wsrx connect ‘把 wss:// 地址粘进来’

成功标志： RX is here -> 127.0.0.1:32833 ← 记下端口

Step 3 抓取网页（终端 2）

curl -s http://127.0.0.1:32833 -o /tmp/case.html
cat /tmp/case.html # 里面有那串大小写被换过的文本

Step 4 切换大小写得到 flag

方法 A（Python swapcase）：

python3 -c “print(‘FLAG{CASE_66643E3F3CF9}’.swapcase())”

方法 B（tr 大小写互换）：

echo ‘FLAG{CASE_66643E3F3CF9}’ | tr ‘A-Za-z’ ‘a-zA-Z’

方法 C（自动抓取+切换脚本，推荐）：

cat > ~/case_decode.py <<’EOF’
import sys, re
html = sys.stdin.read()
m = re.search(r’

(.*?)
‘, html, re.S)
s = (m.group(1) if m else html).strip()
print(s.swapcase())
EOF

python3 ~/case_decode.py < /tmp/case.html

Step 5 提交 flag

  • 整串 flag{…} 复制提交；本平台为小写；不带多余空格、换行。

四、易错点汇总

# 易错点 正确做法
1 以为要全转大写或全转小写 本题是”大小写互换”，不是统一大小写
2 把 { } _ 数字也当字母处理 这些不受影响，别动它们
3 在终端里直接写 .swapcase(FLAG{…}) 要用 python3 -c 或脚本，bash 不认识 swapcase
4 拿上一题的命令来套（如 printf 八进制） 先判断本题是什么变换，再用对应方法
5 用 nc 连网页题 网页题用 curl / 浏览器
6 端口用了旧的 用当前 wsrx 显示的端口

五、下次怎么做（速查卡 · 文字变换类）

—— 文字变换类谜题 速查 ——

页面给一段“变形”文字，判断做了哪种变换，再逆操作：
大小写互换 → s.swapcase() / tr A-Za-z a-zA-Z ← 本题
倒序 → rev / s[::-1]
每个字母位移 → 凯撒，试所有位移
十进制 ASCII→ chr(int(n))
八进制 → chr(int(n,8))
十六进制 → bytes.fromhex / xxd -r -p
base64 → base64 -d

通用：复制到本地 → 脚本试变换 → 找 flag{ }

六、附录

6.1 swapcase 与 tr 用法

‘AbC’.swapcase() # -> ‘aBc’
‘FLAG{X}’.swapcase() # -> ‘flag{x}’
echo ‘AbC’ | tr ‘A-Za-z’ ‘a-zA-Z’ # -> aBc

6.2 Python 常用字符串变换

操作 写法 例子
大小写互换 s.swapcase() ‘Ab’ -> ‘aB’
全大写 s.upper() ‘ab’ -> ‘AB’
全小写 s.lower() ‘AB’ -> ‘ab’
反转 s[::-1] ‘ab’ -> ‘ba’
替换 s.replace(a,b) ‘ab’ -> ‘cb’

6.3 常见“文字/编码变换”题型一览

题型 页面特征 解法
大小写 字母大小写被换过 swapcase / tr
倒过来 字符串逆序 rev / s[::-1]
ASCII 十进制 102 108 … chr(int(n))
八进制 固定三位、数字≤7 chr(int(n,8))
十六进制 66 6c / 0x66 bytes.fromhex / xxd -r -p
Base64 A-Za-z0-9+/=，常见 = 结尾 base64 -d
