【基础】ASCII 码

langkong10132026-09-222026-10-28

—— 知识点详解 · 完整流程 · 脚本 · 易错点 · 速查

平台：ctf.bi6pcr.com（学校网络安全练习赛） | 题目：ASCII 码（100 分）

一、题目回顾

题目描述：页面上每个十进制数是一个 ASCII 码。例如 102 是 f，108 是 l。

提示：chr(102) 得到 f。

换句话说：把网页上那串十进制数字，逐个按 ASCII 表翻译成字符，拼起来就是 flag。

二、知识点详解

2.1 什么是 ASCII 码

计算机内部只能存数字，但我们需要显示字符（字母、数字、符号）。于是人们约定了一张“字符 ↔ 数字”的对照表，这就是 ASCII 表：每个可显示字符都对应一个 0–127 的整数。

  • 例如：字母 f 对应 102，l 对应 108（题目给的例子）；
  • 所以看到一串十进制数字，逐个查表，就能还原成文字。

2.2 数字与字符如何互相转换（重点）

Python 里有两个内置函数，专门做这件事：

方向 函数 例子 结果
数字 → 字符 chr(数字) chr(102) ‘f’
字符 → 数字 ord(字符) ord(‘f’) 102

补充：chr 和 ord 是一对“互逆”函数——chr(ord(x)) 得到 x 本身。

2.3 常用字符的 ASCII 值（务必记住范围）

字符类别 ASCII 范围
空格 32
数字 0 – 9 48 – 57
大写 A – Z 65 – 90
小写 a – z 97 – 122
下划线 _ 95
左花括号 { 123
右花括号 } 125

记住这几个特殊值很有用：flag 里的 { = 123、} = 125、_ = 95。看到 123 和 125 就知道 flag 的括号到了。

2.4 连接知识（网页类容器题，与上一题相同）

这题也是一个“网页类”容器题：平台给 wss:// 地址，用 wsrx 把 wss 映射成本机端口，再用 curl/浏览器打开这个网页。

curl / 浏览器 → http://127.0.0.1:本地端口 → wsrx（隧道） → wss://平台代理 → 容器网页

记住：网页题用 curl 或浏览器，不用 nc。

三、完整操作步骤（Step by Step）

Step 1 在平台创建实例、复制地址

点【创建实例】，等“运行中”；复制那条 wss://… 地址。

Step 2 启动隧道（终端 1，保持运行）

cd ~
./wsrx connect ‘把 wss:// 地址粘进来’

成功标志： RX is here -> 127.0.0.1:34507 ← 记下端口

⚠️ 不要关这个终端、不要按 Ctrl+C。

Step 3 抓取网页（终端 2）

新开标签（Ctrl+Shift+T）：

curl -s http://127.0.0.1:34507 -o /tmp/ascii.html
head -c 300 /tmp/ascii.html # 有输出=隧道通；里面就是那串数字

（或直接在虚拟机里用浏览器打开 http://127.0.0.1:34507）

Step 4 把数字解码成 flag（三种方法）

方法 A（一行命令，最快）：把网页上的数字粘进下面命令：

python3 -c “print(‘’.join(chr(int(n)) for n in ‘102 108 97 103 123 …’.split()))”

方法 B（脚本自动抓取+解码，推荐，长串不出错）：

cat > ~/ascii_decode.py <<’EOF’
import sys, re
html = sys.stdin.read()
m = re.search(r’

(.*?)
‘, html, re.S)
s = m.group(1) if m else ‘’
if not s:
print(‘未找到
标签，页面原始内容前 500 字符：')
    print(html[:500])
else:
    nums = re.findall(r'\d+', s)
    print(''.join(chr(int(n)) for n in nums))
EOF


python3 ~/ascii_decode.py < /tmp/ascii.html


方法 C（手动）：对照文末【附录】的 ASCII 表，一个数字一个数字翻译。适合数字较少时。

6.2 chr / ord 用法小结
chr(102)          # -> 'f'
ord('f')          # -> 102
chr(ord('a'))     # -> 'a'（互逆）


批量解码，例如：
nums = '102 108 97 103'.split()
print(''.join(chr(int(n)) for n in nums))   # -> flag
