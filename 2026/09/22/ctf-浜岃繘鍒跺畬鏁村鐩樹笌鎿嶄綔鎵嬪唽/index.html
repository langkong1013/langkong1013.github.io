【基础】二进制

langkong10132026-09-222026-10-28

—— 知识点详解 · 完整流程 · 脚本 · 易错点 · 速查

平台：ctf.bi6pcr.com（学校网络安全练习赛） | 题目：二进制（100 分）

一、题目回顾

题目描述：页面上每 8 位二进制是一个字节。8 位一组，转回字符，拼起来就是 flag。

提示：int(‘01100110’, 2) 得到一个字节。

思路：把页面上的二进制串，按 8 位一组，转成对应字符即可。

二、知识点详解：二进制

2.1 什么是二进制

二进制是“逢二进一”的进制，只有 0 和 1 两个数字。计算机底层全用二进制存储数据。

2.2 为什么“8 位二进制是一个字节”

一个字节（byte）固定是 8 个二进制位（bit）。8 位二进制能表示 0–255 共 256 个值，正好覆盖一个 ASCII 字符，所以“8 位一组 = 一个字符”。

2.3 二进制 → 字符 怎么算

二进制 按权展开算十进制 对应字符
01100110 64+32+4+2 = 102 f
01101100 64+32+8+4 = 108 l
01111011 64+32+16+8+2+1 = 123 {
01111101 64+32+16+8+4+1 = 125 }

Python 里：int(“01100110”, 2) 得到 102，再 chr(102) 得 f。

2.4 连接知识（网页类容器题）

curl / 浏览器 → http://127.0.0.1:本地端口 → wsrx（隧道） → wss://平台代理 → 容器网页

三、完整操作步骤（Step by Step）

Step 1 创建实例、复制地址

点【创建实例】，等“运行中”，复制 wss://… 地址。

Step 2 启动隧道（终端 1，保持运行）

cd ~
./wsrx connect ‘把 wss:// 地址粘进来’

成功标志： RX is here -> 127.0.0.1:XXXXX ← 记下端口

Step 3 抓取网页（终端 2）

curl -s http://127.0.0.1:XXXXX -o /tmp/bin.html
cat /tmp/bin.html # 里面有那串 8 位一组的二进制

Step 4 把二进制解码成 flag

方法 A（Python 一行）：

python3 -c “print(‘’.join(chr(int(x,2)) for x in ‘01100110 01101100 01100001 01100111’.split()))”

方法 B（bytes + decode）：

python3 -c “print(bytes(int(x,2) for x in ‘01100110 01101100’.split()).decode())”

方法 C（自动抓取+解码脚本，推荐，避免手工抄错）：

cat > ~/bin_decode.py <<’EOF’
import sys, re
html = sys.stdin.read()
m = re.search(r’

(.*?)
‘, html, re.S)
s = m.group(1) if m else html
print(‘’.join(chr(int(x,2)) for x in s.split()))
EOF

python3 ~/bin_decode.py < /tmp/bin.html

Step 5 提交 flag

  • 整串 flag{…} 复制提交；本平台为小写；不带多余空格、换行。

四、易错点汇总

# 易错点 正确做法
1 把二进制当十进制：int(“01100110”) 是错的 必须 int(x, 2) 按二进制解析
2 手工抄二进制时抄错一位（极易发生） 用 curl 抓页面 + 脚本处理，别手抄
3 分组错位：没有按 8 位一组 每 8 位一组，空格就是分组标志
4 前导 0 丢掉：01100110 写成 1100110 保留完整 8 位
5 Python 代码直接粘进 bash，报 “(” 语法错误 包在 python3 -c “…” 里，或存成 .py 脚本
6 用 nc 连网页题 网页题用 curl / 浏览器
7 端口用了旧的 用当前 wsrx 显示的端口
8 Python 一行命令括号放错：chr(int(x,2)for … 先闭合 chr(int(x,2))，再写 for …（详见第五节）

五、本次真实踩坑 · 括号放错位置（🔴 红字 = 错处）

你在提交“二进制”题解时，那条命令一直报错。下面把你当时写的命令原样保留，并用红字标出出错位置。

5.1 当时报的错

TypeError: ‘generator’ object cannot be interpreted as an integer

注意：这是【运行时报错】，不是语法错——说明你的括号“总数是平衡的”，但位置放错了。

5.2 🔴 红字标出错误位置（你的原命令）

python3 -c “print(‘’.join(chr(int(x,2)for x in’01100110 …01111101’.split())))”

红字这一段被 chr() 错误地包了进去——根本原因是它前面少了一个 ) 。

5.3 对照：把括号挪对位置

位置 你的写法（❌） 正确写法（✅）
① int(x,2) 后面 int(x,2)for int(x,2))for
② 命令结尾处 split())) split())

操作：把结尾多出来的那个 )，挪到 int(x,2) 的后面。

5.4 为什么错（原理）

你的写法，等价于：

chr( int(x,2) for x in ‘…’.split() ) # chr() 收到的是『生成器』

正确写法：先闭合 chr(int(x,2))，把 for 交给外层 join()

‘’.join( chr(int(x,2)) for x in ‘…’.split() )

└─生成器元素─┘ └──遍历部分──┘

chr() 只接受一个整数，吃不下生成器，所以报 TypeError。

5.5 ✅ 正确命令（直接复制）

python3 -c “print(‘’.join(chr(int(x,2))for x in’01100110 01101100 01100001 01100111 01111011 01100010 01101001 01101110 01011111 00110110 00110011 00111001 01100010 01100011 01100010 01100001 01100110 00111001 01100110 01100001 00111001 01111101’.split()))”

实测输出：flag{bin_639bcbaf9fa9}（注意 flag 里是字母 i，不是数字 1）

5.6 更不容易写错的替代写法

python3 -c “print(‘’.join([chr(int(x,2)) for x in ‘01100110 …’.split()]))”

用列表推导时，for 天生在 chr() 外面，就不会踩这个坑。

5.7 速记

  • chr( 和 int( 各自成对闭合，写成 chr(int(x,2))。
  • 生成器 A for x in B 里的 A，必须是完整闭合的表达式。
  • 一见 TypeError: ‘generator’ object …，就是『循环被塞进了不该塞的函数里』。

六、下次怎么做（速查卡 · 进制/编码类）

—— 进制/编码类谜题 速查 ——

看数据特征判断是哪一种，再逆操作：
8 位 0/1（01100110） → chr(int(x, 2)) ← 本题
十进制数字（102 108） → chr(int(x))
固定三位、数字≤7（146 154） → chr(int(x, 8))
两位一组（66 6c / 0x66） → bytes.fromhex / xxd -r -p
base64 → base64 -d
倒序 → rev / s[::-1]
每字符写两遍 → s[::2]

通用：curl 抓页面 → 脚本批量转换 → 找 flag{ }

七、附录

字符 二进制 十进制
f 01100110 102
l 01101100 108
a 01100001 97
g 01100111 103
{ 01111011 123
} 01111101 125
_ 01011111 95
（空格） 00100000 32

7.2 各进制转换一行命令

chr(int(‘01100110’, 2)) # 二进制 -> ‘f’
chr(int(‘102’)) # 十进制 -> ‘f’
chr(int(‘146’, 8)) # 八进制 -> ‘f’
chr(int(‘66’, 16)) # 十六进制 -> ‘f’
format(102, ‘b’) # 十进制 -> 二进制 ‘1100110’

7.3 常见“进制/编码”题型一览

题型 页面特征 解法
二进制 8 位一组 0/1 chr(int(x,2))
ASCII 十进制 102 108 … chr(int(x))
八进制 固定三位、数字≤7 chr(int(x,8))
