【基础】八进制

langkong10132026-09-222026-10-28

—— 知识点详解 · 完整流程 · 脚本 · 易错点 · 速查

平台：ctf.bi6pcr.com（学校网络安全练习赛） | 题目：八进制（100 分）

一、题目回顾

题目描述：每个数是一个字节的八进制，固定三位。

页面给出的数字串：

146 154 141 147 173 157 143 164 137 144 067 144 065 141 066 064 070 142 143 063 067 175

按八进制逐个转成字符，得到 flag：

flag{oct_d7d5a648bc37}

二、知识点详解：八进制

2.1 什么是八进制

我们平时用十进制（0–9），计算机用二进制（0–1）。八进制是”逢八进一”的进制，只用数字 0–7。一个八进制位正好对应 3 个二进制位，书写比二进制短，所以常用于表示字节。

2.2 为什么”一个字节固定三位八进制”

一个字节 = 8 个二进制位，最大 255。而 8³ = 512 > 255、8² = 64 < 255，所以一个字节用八进制表示最多需要 3 位，不足 3 位时前面补 0（如 067）。这就是题目说”固定三位”的原因。

2.3 八进制 → 字符 怎么算

八进制 换算成十进制 对应字符
146 1×64+4×8+6 = 102 f
154 1×64+5×8+4 = 108 l
173 1×64+7×8+3 = 123 {
137 1×64+3×8+7 = 95 _
175 1×64+7×8+5 = 125 }

Python 里直接：chr(int(“146”, 8)) 得 f。int(x, 8) 表示”把字符串 x 按八进制解析成整数”。

2.4 连接知识（网页类容器题）

curl / 浏览器 → http://127.0.0.1:本地端口 → wsrx（隧道） → wss://平台代理 → 容器网页

三、完整操作步骤（Step by Step）

Step 1 创建实例、复制地址

点【创建实例】，等“运行中”，复制 wss://… 地址。

Step 2 启动隧道（终端 1，保持运行）

cd ~
./wsrx connect ‘把 wss:// 地址粘进来’

成功标志： RX is here -> 127.0.0.1:34577 ← 记下端口

Step 3 抓取网页（终端 2）

curl -s http://127.0.0.1:34577 -o /tmp/oct.html
cat /tmp/oct.html # 里面有那串三位八进制数

Step 4 把八进制解码成 flag

方法 A（Python 一行）：

python3 -c “print(‘’.join(chr(int(n,8)) for n in ‘146 154 141 147 173 …’.split()))”

方法 B（printf 八进制转义，Linux 自带）：

printf ‘\146\154\141\147\173’ # 输出 flag{

方法 C（自动抓取+解码脚本，推荐）：

cat > ~/oct_decode.py <<’EOF’
import sys, re
html = sys.stdin.read()
m = re.search(r’

(.*?)
‘, html, re.S)
s = m.group(1) if m else html
nums = re.findall(r’\b[0-7]{2,3}\b’, s)
print(‘’.join(chr(int(n, 8)) for n in nums))
EOF

python3 ~/oct_decode.py < /tmp/oct.html

Step 5 提交 flag

  • 整串 flag{…} 复制提交；本平台为小写；不带多余空格、换行。

四、易错点汇总

# 易错点 正确做法
1 把八进制当十进制：把 146 直接 chr(146)（那是别的字符） 必须 chr(int(n,8)) 按八进制解析
2 忘记前导 0：067 要看成一个整体 保留三位（067 就是 55）
3 int(n) 默认十进制，解析错 显式写 int(n, 8)
4 用 nc 连网页题 网页题用 curl / 浏览器
5 从整页提取数字，混入 CSS 数字 只从 
 里取，或用 \b[0-7]{2,3}\b 限定
6 端口用了旧的 用当前 wsrx 显示的端口
7 大小写/括号不符、只复制括号内 按平台小写格式、整串 flag{...} 提交

五、下次怎么做（速查卡 · 进制/编码类）

—— 进制/编码类谜题 速查 ——

看数字特征判断进制，再按对应方式转字符：
十进制数字（102 108） → chr(int(n))
固定三位、数字≤7（146 154） → chr(int(n, 8)) ← 本题
十六进制（66 6c / 0x66） → chr(int(n,16)) / xxd -r
二进制（01100110） → chr(int(n,2))
base64 → base64 -d
倒序 → rev / s[::-1]

通用：先复制到本地 → 用脚本批量转换 → 找 flag{ }

六、附录

6.1 多进制对照表（常用字符）

字符 十进制 十六进制 八进制
f 102 66 146
l 108 6C 154
{ 123 7B 173
_ 95 5F 137
} 125 7D 175
7 55 37 067

6.2 各进制转换一行命令

chr(int('102')) # 十进制 -> 'f'
chr(int('146', 8)) # 八进制 -> 'f'
chr(int('66', 16)) # 十六进制 -> 'f'
chr(int('1100110', 2)) # 二进制 -> 'f'
format(102, 'o') # 十进制 -> 八进制 '146'
format(102, 'x') # 十进制 -> 十六进制 '66'

6.3 常见“进制/编码”题型一览

题型 页面特征 解法
ASCII 十进制 102 108 … chr(int(n))
八进制 固定三位、数字≤7：146 154 chr(int(n,8))
十六进制 66 6c / 0x66 chr(int(n,16)) / xxd -r
二进制 01100110 chr(int(n,2))
Base64 A-Za-z0-9+/=，常见 = 结尾 base64 -d
倒过来 字符串逆序 rev / s[::-1]
