零基础详解版 —— 页面”没东西”时看 robots.txt，顺着 Disallow 找隐藏目录，Python 代码逐行讲解

一、题目信息

项目 内容
题名 维护中
页面 只显示

维护中

，没有任何线索
题型 Web —— robots.txt 泄露隐藏路径
最终 flag flag{porch_0f5653c60a07}

二、题目现象

首页非常”干净”，就一句话：

维护中

看起来什么都没有。这时候第一反应应该是：去问服务器”有哪些地方不希望被爬虫碰”。

请求 /robots.txt：

User-agent: *
Disallow: /s/note

它明确写了一条 Disallow: /s/note —— 等于主动告诉了我们一个隐藏地址。

GET /s/note ->
flag{porch_0f5653c60a07}

三、前置知识（零基础也能懂）

3.1 robots.txt 是什么

robots.txt 是一个放在网站根目录的纯文本文件，用来告诉搜索引擎爬虫”哪些页面可以抓、哪些不要抓”。格式是：

字段 含义
User-agent: * 对”所有”爬虫生效（* 是通配）
Disallow: /s/note 不要访问 /s/note 这个路径
Allow: … 允许访问（和 Disallow 相反）

3.2 为什么 Disallow 是线索

robots.txt 本来只是”礼貌约定”，但很多网站会把不想被公开的地址写进 Disallow。所以里面出现的路径，往往是不想让你看见的敏感页——反过来正好是我们想找的。

3.3 “维护中”页面的破解思路

页面没内容时，别只盯着首页。要按顺序找”藏起来的入口”：

顺序 看什么
1 robots.txt / sitemap.xml
2 源码里的 src= / href= / 注释
3 常见路径字典：/admin /backup /api /.git/config …
4 响应头（Server、X-Powered-By 等）

四、解题思路（为什么这么做）

  • 第 1 步：首页空白 → 去看 robots.txt。
  • 第 2 步：robots.txt 里 Disallow: /s/note → 得到一个隐藏路径。
  • 第 3 步：访问 /s/note → flag 就在里面。

一句话：页面越”干净”，越要翻服务器主动交出来的”清单”（robots.txt）。

五、逐步操作（三种方式，任选其一）

方式一 浏览器

  • 在地址栏输入 <网址>/robots.txt 回车 → 看到 Disallow: /s/note。
  • 再把地址改成 <网址>/s/note → 页面上直接显示 flag。

方式二 curl 两条

curl -s http://127.0.0.1:<端口>/robots.txt
curl -s http://127.0.0.1:<端口>/s/note

方式三 Python（推荐，能自动顺着 robots 找）

import re, requests

base = ‘http://127.0.0.1:<端口>’

1) 首页什么都看不到 -> 先看 robots.txt

rb = requests.get(base + ‘/robots.txt’).text
print(‘robots.txt:’); print(rb)

2) 从 robots.txt 里抓出被 Disallow 的隐藏路径

paths = re.findall(r’Disallow:\s*(\S+)’, rb) # 得到 [‘/s/note’]
print(‘隐藏路径:’, paths)

3) 逐个访问，找 flag

for p in paths:
t = requests.get(base + p).text
m = re.search(r’flag{[^}]*}‘, t)
if m:
print(‘flag =’, m.group(0))

代码 作用 · 原理
requests.get(base + ‘/robots.txt’).text 取 robots.txt 内容
re.findall(r’Disallow:\s*(\S+)’, rb) 正则抓出所有 Disallow 后面的路径
for p in paths: requests.get(base + p) 依次访问这些隐藏路径
re.search(r’flag{[^}]*}‘, t) 在返回里找 flag

补充：只能走 wss 隧道时

import ssl, websocket

URL = ‘wss://ctf.bi6pcr.com/api/proxy/<实例uuid>’

def http(path):
ws = websocket.create_connection(URL, timeout=25,
header=[‘Origin: https://ctf.bi6pcr.com'],
sslopt={‘cert_reqs’: ssl.CERT_NONE})
ws.send(‘GET %s HTTP/1.1\r\nHost: 127.0.0.1\r\n’
‘Accept: /\r\nConnection: close\r\n\r\n’ % path)
buf = b’’
while True:
try:
d = ws.recv()
except Exception:
break
if not d:
break
buf += d if isinstance(d, bytes) else d.encode(‘latin1’)
ws.close()
return buf.partition(b’\r\n\r\n’)[1]

print(http(‘/robots.txt’).decode(‘utf-8’, ‘replace’)) # 泄露路径
print(http(‘/s/note’).decode(‘utf-8’, ‘replace’)) # flag

代码 作用 · 原理
http(path) 封装”经隧道发 GET 请求”，返回正文
buf.partition(b’\r\n\r\n’)[1] 按空行切开，取后半段（正文）

六、结果

七、易错点

现象 / 报错 原因 解决
首页没线索就放弃 没找隐藏入口 先看 robots.txt / sitemap.xml
robots.txt 404 这台服务器没放 改用路径字典扫 /admin /backup 等
/s/note/ 报错 多了斜杠 用 /s/note，注意结尾不要多加 /
抓到空内容 路径大小写/拼写不符 严格照 robots.txt 里的原文

思路：首页空白 -> 看 robots.txt -> Disallow 泄露 /s/note -> 访问它
