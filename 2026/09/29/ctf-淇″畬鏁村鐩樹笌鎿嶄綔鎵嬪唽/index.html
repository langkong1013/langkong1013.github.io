三、前置知识（零基础也能懂）

3.1 HTML 注释

注释是给开发者看的说明，不会显示在页面上，但在源码里能看到。很多题的 flag 或提示就藏在注释里。

3.2 Cookie 与响应头

服务器可以在响应头里用 Set-Cookie 给浏览器"发小纸条"，之后浏览器每次请求都带回来。用 curl -i 或 Python 的 r.cookies 都能看到它。
