Bandit 1–15 关 Linux 基础操作详解

langkong10132026-09-212026-10-28

—— 命令 · 原理 · 易错提醒（配套 OverTheWire Bandit 闯关）

适用：Linux 零基础 / CTF 入门 · 2026-09

〇、总览：关卡 ↔ 命令对照表

关卡 任务要点 核心命令
0 通过 SSH 登录服务器 ssh
0→1 读主目录里的 readme 文件 ls、cat
1→2 文件名是单个 - cat ./-
2→3 文件名带空格、以 – 开头 cat “./…”、cat –
3→4 隐藏文件（. 开头） cd、ls -a
4→5 唯一”人类可读”的文件 file
5→6 大小正好 1033 字节、不可执行 find -type -size -executable
6→7 大小 33 字节、属主/属组指定 find -user -group -size + 2>/dev/null
7→8 某行含关键字 millionth grep
8→9 只出现一次的那一行 sort、uniq -u
9→10 二进制里含 “=” 的文本 strings、grep
10→11 内容是 base64 编码 base64 -d
11→12 内容是 ROT13 加密 tr
12→13 十六进制 + 多层压缩（gzip/bzip2/tar） xxd -r、file、gzip/bzip2/tar
13→14 用私钥文件登录 ssh -i、chmod 600
14→15 向某端口发送数据 nc
15→16 通过 SSL 发送数据 openssl s_client

下面按”知识主题”逐一详解，每个主题都标注了它对应哪一关。

一、连接服务器：SSH

1.1 基本用法

ssh 用户名@主机地址 -p 端口号

例：ssh bandit0@bandit.labs.overthewire.org -p 2220

  • 首次连接会问 “Are you sure you want to continue connecting” → 输入 yes 回车；
  • 随后提示 password：→ 输入密码。输入密码时屏幕不显示任何字符，这是正常的。
  • 退出登录：输入 exit。

1.2 用私钥登录（第 13→14 关）

chmod 600 sshkey.private # 私钥权限必须是 600，否则报错
ssh -i sshkey.private bandit14@localhost -p 2220

易错提醒 ⚠️

  • 端口务必写对：Bandit 是 2220，不是 22；
  • 私钥权限过宽（如 777）会被拒绝：”permissions are too open” → chmod 600 修正；
  • 若报 Connection closed（刚握手就被断）：多半是 VMware NAT + 新 OpenSSH 的 IPQoS 问题，加 IPQoS throughput 即可。

二、浏览文件与目录

命令 作用 示例
pwd 显示当前所在目录 pwd
ls 列出目录内容 ls / ls -l / ls -a / ls -la / ls -lh
ls -a 显示隐藏文件（含 . 开头） ls -a
ls -l 显示详细信息（权限/属主/大小） ls -l
cd 切换目录 cd inhere / cd .. / cd ~ / cd -
cat 一次性输出文件内容 cat readme
less 分页查看（大文件用） less bigfile（空格翻页，q 退出）
head / tail 看开头 / 结尾若干行 head -n 5 f / tail -f f

易错提醒 ⚠️

  • cat 二进制文件会刷一屏乱码，还可能把终端显示搞乱 → 敲 reset 回车恢复；
  • cat 只能读”文件”，不能读目录（读目录用 ls）。

三、处理特殊文件名（重点，第 1→2、2→3 关）

Linux 里空格是”参数分隔符”，而”以 - 开头”会被当成命令选项。两类特殊文件名要会处理：

情况 解决办法 示例
文件名以 - 开头 前面加 ./ cat ./-file00
文件名带空格 用引号包住，或 \ 转义 cat “my file.txt” / cat my\ file.txt
以 – 开头 + 带空格 两者结合 cat “./–spaces in this filename–”
想让程序把 – 后都当文件名 用 – 分隔符 cat – “–spaces in this filename–”

原理

    • 单独出现时，很多命令把它理解为”标准输入/输出”（如 cat - 会等你从键盘输入）；
  • ./ 表示”当前目录”，加前缀后参数不再以 - 开头，就不被当选项了；
  • 通配符 * 匹配到的文件若以 - 开头，同样可能被当选项，注意用 ./ 。

四、隐藏文件（第 3→4 关）

  • 以 . 开头的文件/目录是”隐藏”的，普通 ls 看不到，必须 ls -a 或 ls -la；
  • . 代表当前目录，.. 代表上级目录（所以 ls -a 里总有 . 和 ..）；
  • 常见隐藏文件：.bashrc、.profile（shell 配置）。

五、判断文件类型：file（第 4→5 关）

file 通过读取文件头部的”魔数”判断文件真实类型，做 Misc/取证题必备。

file ./* # 查看当前目录所有文件的类型

输出里 ASCII text 表示是文本文件；data / 其它表示二进制

易错提醒 ⚠️

  • 扩展名不可信（一个 .txt 也可能是图片），以 file 的结果为准；
  • 二进制文件里想找文本，用 strings（见第七节）。

六、查找文件：find（核心重点，第 5→6、6→7 关）

6.1 语法

find [从哪找] [条件…] [动作…]

6.2 常用条件

条件 含义
-name “模式” 按文件名（支持 * 通配）
-type f / d / l 普通文件 / 目录 / 链接
-size 1033c 大小为 1033 字节（c=字节；k=KB；M=MB）
-user 用户名 属主是某用户
-group 组名 属组是某组
-perm 644 权限恰好为 644
-executable / ! -executable 可执行 / 不可执行
-maxdepth 1 只找一层，不递归
! 条件 取反（排除）

6.3 本阶段两关的标准命令

第 5→6 关：找大小1033字节、不可执行的普通文件

find . -type f -size 1033c ! -executable

第 6→7 关：全盘找 属主bandit7、属组bandit6、大小33字节 的文件

find / -user bandit7 -group bandit6 -size 33c 2>/dev/null

6.4 万能套路（以后 CTF 常用）

find / -name “flag*” 2>/dev/null # 全盘找名字含 flag 的文件
find . -name “*.txt” # 找所有 txt
find . -type f -exec grep -l “flag” {} ; # 找到后对每个文件搜内容

易错提醒 ⚠️

  • -size 的坑：默认单位是 512 字节块！要按”字节”必须加 c，如 -size 1033c；
  • ! 与后面的条件之间要有空格：! -executable；
  • 权限报错太多时，末尾加 2>/dev/null 屏蔽错误信息；
  • find 默认递归所有子目录，20 个文件夹也能一次找完。

七、文本搜索与处理：grep / sort / uniq / strings / cut

命令 作用 常用选项与示例
grep 按关键字搜索文本 grep millionth data.txt ；-i 忽略大小写，-n 行号，-v 反选，-r 递归
sort 按行排序 sort data.txt ；-n 数字序，-r 倒序
uniq 去除”相邻”重复行 sort f | uniq -u ；-c 统计次数，-u 只显示唯一行，-d 只显示重复行
strings 从二进制里抽出可打印字符串 strings data.txt | grep “=”
cut 按列提取 cut -d ‘:’ -f1 passwd

对应关卡

  • 第 7→8 关：grep millionth data.txt —— 找含关键字的那一行；
  • 第 8→9 关：sort data.txt | uniq -u —— 先排序再找”只出现一次”的行（uniq 只能处理相邻重复，所以必须先 sort）；
  • 第 9→10 关：strings data.txt | grep "=" —— 二进制里找含 = 的可读文本。

八、编码与转换（第 10→11、11→12、12→13 关）

8.1 base64（第 10→11 关）

base64 -d data.txt # -d = decode 解码（不加 -d 是编码）

8.2 ROT13（第 11→12 关）

ROT13 是把每个字母后移 13 位（A↔N，B↔O…），加密解密是同一个操作。用 tr 做字符替换：

tr ‘A-Za-z’ ‘N-ZA-Mn-za-m’ < data.txt

8.3 十六进制还原（第 12→13 关）

xxd data.txt # 查看十六进制表示
xxd -r data.txt > out # -r 反向：把十六进制文本还原成原文件

8.4 tr 通用用法

  • 字符替换/删除：tr 旧字符集 新字符集 ；-d 删除字符；-s 压缩重复字符。

九、压缩与解压（第 12→13 关）

命令 作用
gzip -d f.gz / gunzip f.gz 解 gzip
bzip2 -d f.bz2 解 bzip2
tar xf f.tar 解 tar
tar xzf f.tar.gz 解 tar.gz
file f 判断到底是哪种格式（扩展名可能骗人）

第 12→13 关的套路

  • 这个文件被反复压缩了多次，而且后缀名会骗人；
  • 循环：file 文件 判断真实类型 → 用对应命令解压 → 改名 → 再看 → 直到变成 ASCII text；
  • 常见顺序：hexdump(xxd -r) → gzip → bzip2 → tar → … → 最后是文本密码。

十、网络工具：nc / openssl / nmap（第 14→15、15→16 关）

10.1 nc（netcat）—— 发送数据到端口

nc localhost 30000 # 连上后手动输入内容
echo “密码” | nc localhost 30000 # 直接把密码发过去

10.2 openssl —— 走 SSL/TLS 的加密连接

openssl s_client -connect localhost:30001

连上后输入上一关密码，服务器会回给你下一关密码

10.3 nmap —— 端口扫描（后面关卡会用）

nmap -p 31000-32000 localhost

一句话区分

  • nc = 明文连接；openssl s_client = 加密连接（多了 SSL 握手）。

十一、管道与重定向（贯穿全程）

符号 含义
| 管道：把前一个命令的输出，作为后一个命令的输入
> 覆盖写入文件
>> 追加写入文件
< 从文件读入
2> 把错误信息写入文件
2>&1 把标准输出和错误一起处理
2>/dev/null 丢弃错误信息（常用）

sort data.txt | uniq -u # 管道组合示例
strings data.txt | grep “=” # 管道组合示例

十二、权限基础（读懂 ls -l）

-rw-r—– 1 bandit1 bandit0 438 Jun 24 14:58 readme

字段 含义
第1位 - / d - 普通文件；d 目录；l 链接
后9位 rwxrwxrwx 三组：属主 / 属组 / 其他人，各占 r读(4) w写(2) x执行(1)
数字 硬链接数
bandit1 属主
bandit0 属组
438 文件大小（字节）
  • chmod 600 file：设权限为”属主可读写、其他人无权”（私钥必须这样）；
  • chmod +x file：给所有用户加执行权限；
  • 后面关卡会用到 setuid（属主执行位为 s），届时再深入。

附录：事半功倍的小习惯

  • 快捷键：Tab 补全、↑ 翻历史、Ctrl+R 搜历史、Ctrl+C 中断、Ctrl+L 清屏；
  • 随时求助：man 命令（q 退出）、命令 --help、网站 explainshell.com 解析整条命令；
  • 记笔记存本地（服务器主目录不可写）；密码随做随记；
  • 卡住先自己试：看不懂的英文说明多读两遍，先 ls -la 看全貌。
