CTF 入门知识清单（零基础详解版）

langkong10132026-09-232026-10-28

—— 把你做过的题，串成一张能查、能学、能复用的知识地图

来源：本清单整理自你已完成的题目（签到 / 摩尔斯 / ASCII / 倒过来 / 八进制 / 十六进制 / 大小写 / 写了两遍 / 二进制 / URL编码 / ROT13 / 凯撒密码 / 阿特巴什 / 办公电脑）以及 OverTheWire Bandit 1–15 关。

一、怎么用这份清单

  • 按“块”学：编码/进制 → 古典密码 → 字符串变换 → Linux 基础 → 受限环境 → 工具 → 思维。
  • 每个知识点都给了：① 怎么认出它（特征）② 原理 ③ 用什么命令/方法 ④ 对应你做的哪道题。
  • 遇到新题：先看“特征”，去清单里对号入座，再套“解法”。

二、第一块：进制与基础编码

这一块的核心思路只有一句：看清楚数据长什么样，找到对应的“逆操作”把它变回人类可读的字符。

类型 怎么认（特征） 解法（命令/方法） 对应题
十进制 ASCII 一堆普通数字，如 102 108 97 103 python3 -c “print(‘’.join(chr(int(x)) for x in s.split()))” ASCII 码
八进制 固定三位一组、每位≤7，如 146 154 chr(int(x, 8)) 八进制
十六进制 两位一组或带 0x，如 66 6c / 0x66 bytes.fromhex() / xxd -r -p 十六进制
二进制 8 位一组的 0/1，如 01100110 chr(int(x, 2)) 二进制
Base64 只含 A-Za-z0-9+/ 且常以 = 结尾 base64 -d （常考）
URL 编码 到处都是 %xx，如 %7B %7D urllib.parse.unquote URL 编码
Unicode 转义 形如 \u4f60\u597d .encode().decode(‘unicode_escape’) —
HTML 实体 形如 { & html.unescape —
摩尔斯电码 由 . 和 - 及空格组成 查表 / 手写映射 摩尔斯

2.1 十进制 ASCII：字符的“编号”

  • 原理：每个字符在计算机里都对应一个整数编号（ASCII 码）。f=102、l=108、{=123。
  • 识别：一串普通数字、两位数/三位数、范围和 32–126 之间。
  • 解法：把每个数字当作编号，反过来查出字符——chr(数字)。

chr(102) -> ‘f’ ；批量：拆开后逐个 chr 再拼起来

python3 -c “print(‘’.join(chr(int(x)) for x in ‘102 108’.split()))” # -> fl

2.2 八进制：以 8 为基

  • 原理：八进制只有 0–7，逢 8 进 1。字符 f 的编号 102，转成八进制是 146。
  • 识别：一组“固定三位、每位不超过 7”的数字，最像八进制。
  • 解法：chr(int(x, 8))——告诉 Python“按 8 进制读这个数”。

python3 -c “print(chr(int(‘146’, 8)))” # -> f

2.3 十六进制：以 16 为基

  • 原理：十六进制用 0-9 和 a-f；两位十六进制 = 一个字节（8 位）。f=0x66。
  • 识别：两位一组、含 a-f，或带 0x 前缀。
  • 解法：bytes.fromhex(“66 6c”) 直接得到字节；或 xxd -r -p 还原。

python3 -c “print(bytes.fromhex(‘666c’)).decode()” # -> fl
echo ‘666c’ | xxd -r -p # -> fl

2.4 二进制：以 2 为基

  • 原理：只有 0/1；8 位二进制 = 一个字节，正好覆盖一个 ASCII 字符。
  • 识别：8 位一组的 0/1（前面常有前导 0，别丢）。
  • 解法：chr(int(x, 2))。

python3 -c “print(‘’.join(chr(int(x,2)) for x in ‘01100110 01101100’.split()))” # -> fl

2.5 Base64：把二进制“翻译”成 64 个安全字符

  • 原理：用 A-Za-z0-9+/ 共 64 个字符表示数据；每 3 字节 → 4 个字符，不足处用 = 补齐。
  • 识别：只含大小写字母、数字、+、/，末尾可能有 =。
  • 解法：base64 -d（d=decode 解码）。

echo ‘ZmxhZw==’ | base64 -d # -> flag
echo -n ‘flag’ | base64 # 反向：编码 -> ZmxhZw==

2.6 URL 编码：% 加两位十六进制

  • 原理：URL 里不能直接写空格、中文、{} 等，就用 %+两位十六进制表示。{=0x7B→%7B。
  • 识别：遍地 %xx；%7B/%7D 通常就是 { }。
  • 解法：urllib.parse.unquote 整段解码。

python3 -c “import urllib.parse; print(urllib.parse.unquote(‘%66%6c%61%67%7b%7d’))”

2.7 Unicode 转义 / HTML 实体（补充）

  • Unicode 转义：\u4f60\u597d 这种，用 .encode().decode(“unicode_escape”) 还原。
  • HTML 实体：{ 是 {、（网页里的 &）用 html.unescape 还原。

2.8 摩尔斯电码

  • 原理：用“点 .”和“划 -”的组合表示字母/数字，字母之间空格、单词之间更长间隔。
  • 识别：一串 . 和 -。
  • 解法：查对照表逐段翻译（注意本题里 }=-.-. {=.-… _=..–.-）。

三、第二块：古典密码

共同点：只动“字母”，数字、下划线、花括号都不动——这是和“编码”最大的区别。

类型 原理 解法 对应题
凯撒密码 每个字母平移固定的 N 位 枚举 N=1..25，找含 flag 的那行 凯撒密码
ROT13 平移 13 位（自逆） tr ‘A-Za-z’ ‘N-ZA-Mn-za-m’ ROT13
阿特巴什 字母表翻转（自逆） tr a..z z..a 阿特巴什

3.1 凯撒密码

  • 原理：字母按固定位数平移（密钥 = 平移量 N）。如后移 3 位：a→d、z→c。
  • 为什么好破：只有 25 种可能，全试一遍即可（暴力枚举）。
  • 解法：写个循环试 N=1..25，输出里出现 flag 的就是答案。

3.2 ROT13

  • 原理：凯撒的特例，N=13。因为 26÷2=13，移两次=移 26=回到原样，所以它“自己就是自己的逆运算”。
  • 解法：再移一次即还原；tr 或 codecs.decode(s, “rot13”)。

3.3 阿特巴什（Atbash）

  • 原理：把字母表对折——第 1 个↔第 26 个（a↔z、b↔y…m↔n）。
  • 同样自逆：做两次回到原样。
  • 解法：tr a..z z..a，或用位置 25−i 计算。

四、第三块：字符串变换（看“形状”就能猜）

类型 特征 解法 对应题
倒序 整段文字倒着读才通顺 rev / s[::-1] 倒过来
大小写错乱 大小写被逐个反转（fLaG） swapcase() / tr 大小写
每字符写两遍 每个字符重复出现两次 s[::2] 取每隔一个 写了两遍
两串交错 两段内容交替出现 s[::2] + s[1::2] 再拼 —
  • s[::-1] 是 Python 切片：从头到尾、步长 -1，等于把字符串倒过来。
  • s[::2] 表示“每隔一个取”，正好把“写了两遍”的内容还原成一半。

五、第四块：Linux 命令行基础（Bandit + 办公电脑的核心）

5.1 浏览与读取文件

命令 作用 常用参数 例子
pwd 显示当前所在目录 — pwd
ls 列出目录内容 -l 长格式 / -a 含隐藏 / -h 易读 ls -la
cd 切换目录 ~ 家目录 / .. 上级 / . 当前 cd /tmp
cat 把文件内容打印出来 — cat README
file 判断文件是什么类型 — file a.bin
head / tail 看开头 / 结尾若干行 -n 数字 head -n 5 f
wc 统计行数/词数/字符数 -l 只数行 wc -l f

5.2 查找文件与内容

命令 作用 关键参数 例子
find 按条件找文件 -name 名字 / -type 类型 / -size 大小 / -user 属主 / -exec 执行 find / -size 33c
grep 按“内容”搜 -r 递归 / -i 忽略大小写 grep -r “flag” .
which 找某命令在哪 — which python3
  • find 的 -size 数字后面要带单位：c=字节（如 33c）；不带单位是“块”。

5.3 文本处理（“读不到就用别的工具读”）

命令 作用 例子
sort 把行排序 sort f
uniq 去掉相邻重复行（常配合 sort） sort f | uniq -u
strings 从文件里提取可打印文字 strings f | grep flag
cut 按列切分 cut -d: -f1
tr 字符替换/删除 tr a-z A-Z
xxd / od 十六进制/八进制转储（-r 可反解） xxd -r -p f
base64 Base64 编解码（-d 解码） base64 -d f

5.4 权限与身份（办公电脑那题的关键）

命令/概念 作用 说明
whoami / id 看“我是谁” id 显示 uid、组
ls -l 权限位 看文件权限 如 -r——– 表示仅属主可读
chmod 改权限 +r 加读；644/755 数字法
chown 改属主 通常需管理员
sudo 以管理员身份运行 临时提权
  • 权限三组三开关：属主(u)/属组(g)/其他人(o) × 读(r)/写(w)/执行(x)。
  • 关键原理：属主给自己的文件改权限，不需要文件本身有权限——所以哪怕文件是 ———-，你也能 chmod +r。

5.5 网络、管道、通配符、压缩

命令/符号 作用 例子
ssh 远程登录另一台机器 ssh user@host -p 2220
nc (netcat) 连接某 IP:端口，收发数据 nc 127.0.0.1 37591
curl 发 HTTP 请求 / 下载 curl -s URL -o f
wget 下载文件 wget URL
| 管道 把前一条命令的输出，当作后一条的输入 cat f | grep flag
> / >> 重定向到文件（覆盖 / 追加） echo x > f
< 把文件当输入 cmd < f
* ? [] 通配符：任意 / 一个 / 集合 ls *.txt
tar 打包/解包（-z 配合 gzip） tar xf a.tar.gz
gzip 压缩/解压（-d 解压） gzip -d a.gz
  • 通配符小技巧：文件名看不清/怕敲错时，用 * 代替（如 cat README*）。

六、第五块：受限环境与“曲线救国”技巧（办公电脑）

  • 受限 shell（jail）：一个被裁剪过的 shell，很多命令被删除或禁用。
  • busybox：把上百个命令打包进“一个”文件的“多合一工具箱”；很多命令只是它的符号链接。
  • setpriv：以指定身份/权限运行另一个程序——用来“借道”调用被禁用的 busybox：

setpriv busybox cat <文件> # 借用 busybox 的 cat 读文件
setpriv busybox chmod +r <文件> # 借用 busybox 的 chmod 加权限

  • 重要坑：当 shell 里没有 cat 时，报错是 “No such file or directory”——它说的是“找不到 cat 命令”，不是“文件不存在”。别被误导。
  • 另一个坑：setpriv –nnp 想提权读文件，若该环境 uid 0 不是真 root，会 Permission denied——此时改用“属主 chmod”。

七、第六块：常用工具与平台

工具 作用 用法
wsrx 把平台的 wss:// 地址转成本地端口（隧道） ./wsrx connect ‘wss://…’
nc 连接转换出来的本地端口 nc 127.0.0.1 端口
python3 -c 一行执行 Python 代码 python3 -c “…”
xxd / base64 / tr 命令行版编解码工具 见上文

八、命令行避坑指南（引号 · 空格 · 斜杠）

这一节专门收集初学者最常犯、又最难自己看出来的命令行错误。统一格式：❌ 错误写法 → 报错 → 原因 → ✅ 正确写法。

8.1 铁律：命令与参数之间必须有空格

❌ 错误写法 报错 原因 ✅ 正确写法
tr’abc’ ‘def’ 未找到命令 trabc… tr 和参数粘成了一个词，成了不存在的命令 tr ‘abc’ ‘def’
… |tr ‘a’ ‘b’ 管道后缺空格 管道符 | 后面也要有空格 … | tr ‘a’ ‘b’
cd/etc 未找到命令 cd/etc 命令与路径之间要有空格 cd /etc

8.2 参数含空格 / 括号 / 特殊符号时，用引号包起来

  • python3 -c print(‘x’) → bash 报“未预期的记号 (”——因为代码没被引号包住。
  • 正确：python3 -c “print(‘x’)”（用双引号把整段代码包起来）。
  • 文件名含空格：cat ‘my file.txt’（加引号），或 cat my\ file.txt（用反斜杠转义空格）。

8.3 单引号 vs 双引号

写法 特点 例子
‘ 单引号 ‘ 里面内容全部当普通字符（最安全） echo ‘$PATH’ → 原样输出 $PATH
“ 双引号 “ $变量、\ 会被 shell 解释 echo “$PATH” → 输出变量的值

8.4 斜杠方向：Linux 用 /（正斜杠），不是 \

  • 路径分隔符是 /；反斜杠 \ 在 Linux 里是“转义符”，不是目录分隔符。
  • 错误：ls \bin ；正确：ls /bin 。（只有 Windows 才用 \）

8.5 相邻引号会自动合并

  • ‘abc’’def’ 会被 shell 合并成一个参数 abcdef —— 给 tr 这类命令传两个集合时，别写成相邻引号。

8.6 一句话总结

  • 命令和参数之间要空格；有特殊符号就上引号；路径用正斜杠 /；两个参数别用相邻引号。

九、第七块：通用解题思维（比命令更重要）

  • 先看特征、再对号入座：数字？%xx？8位0/1？纯字母被平移？——每种特征对应一种解法。
  • 逆操作思维：题目怎么变的，你就怎么反着来（编码↔解码、平移↔反向平移、翻转↔再翻转）。
  • 暴力枚举：可能空间小就直接全试（凯撒 25 种）。
  • 就地取材 + 信息收集：先 ls 看有什么；找不到工具就用别的工具（strings/tar/shuf 都能“读”文件）。
  • 从报错反推：报错往往在告诉你“哪个环节错了”（命令不存在 / 权限不足 / 路径不对）。
  • 留意“第一个文件/README”：不少题会把线索或第一段 flag 放在 README 里。

十、附录：编码转换一览（可直接复制）

chr(int(x)) # 十进制 -> 字符
chr(int(x, 8)) # 八进制 -> 字符
chr(int(x, 16)) # 十六进制 -> 字符
chr(int(x, 2)) # 二进制 -> 字符
bytes.fromhex(s) # 十六进制串 -> 字节
s.encode().decode(‘unicode_escape’) # \u 转义 -> 字符
html.unescape(s) # HTML 实体 -> 字符
urllib.parse.unquote(s)# URL 编码 -> 字符
base64 -d # Base64 -> 原文
s[::-1] / rev # 倒序
s[::2] # 每隔一个取（还原“写了两遍”）
swapcase() # 大小写互换
codecs.decode(s,’rot13’) # ROT13
tr ‘a-z’ ‘A-Z’ # 大小写转换（命令行）

命令速查（Linux 常用）

ls -la / pwd / cd / cat / file / head / tail / wc
find / -name “flag“ 2>/dev/null
grep -r “flag” . # 递归搜内容
sort f | uniq -u # 找唯一行
strings f | grep -i flag
chmod +r f # 加读权限（属主）
setpriv busybox cat f # 受限环境借道读文件
