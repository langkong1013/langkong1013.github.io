零基础手算详解版 —— 嵌套压缩包逐层解包 + PNG 图片 LSB 隐写，Python 代码逐行讲解

一、题目信息

项目 内容
题名 【比赛】层层包（1000 pts）
提示 包里还有包，最里面是一张图。
入口 http://127.0.0.1:<端口>/（实例本机地址）
代理隧道 wss://ctf.bi6pcr.com/api/proxy/01a0d8f6-967d-7d0c-966b-a069015ae7bd
附件 bundle.tar（10240 字节，内含 bag.zip）
题型 杂项 —— 嵌套压缩包 + 图片 LSB 位隐写
最终 flag flag{m80_c39a54494c64}

二、前置知识（零基础也能懂）

2.1 嵌套压缩包

把一个压缩包再塞进另一个压缩包里，就要”解了一层还有一层”。本题就是：tar → zip → 图片。核心动作只有两步：判断类型 + 按类型解压，反复做。

2.2 怎么判断一个文件是什么？

不能只看扩展名（里面那层常常没有后缀）。用 file 命令看”魔数/特征”：

文件类型 开头特征(魔数) file 显示
tar （无固定魔数，靠结构） POSIX tar archive
gzip 1F 8B gzip compressed data
zip 50 4B 03 04（PK..） Zip archive data
PNG 图片 89 50 4E 47 0D 0A 1A 0A PNG image data, 32 x 7
BMP 图片 42 4D（BM） PC bitmap

2.3 PNG 图片结构

区域 内容
文件头 固定 8 字节 89 50 4E 47 0D 0A 1A 0A（PNG 签名）
IHDR 块 含宽度、高度、位深、颜色类型
IDAT 块 压缩后的像素数据
IEND 块 结束标志

2.4 LSB（最低位）位隐写

把 0/1 信息藏进像素颜色的最低位：如 R 值 128(…0000) 和 129(…0001) 只差最后 1 位，肉眼分辨不出，但程序按位取回就是比特。本题正是把 flag 编成比特写进 R 通道最低位。

三、解题思路（为什么这么做）

  • 第 1 步：通过 wss 隧道取回 bundle.tar。
  • 第 2 步：解 tar → 得到 bag.zip；解 zip → 得到 shot.png 和 noise.txt。
  • 第 3 步：noise.txt 内容只是 “nothing”（诱饵）。
  • 第 4 步：读 shot.png，发现 R 通道只有 128/129 两个值 → LSB 是比特。
  • 第 5 步：按位提取 → 每 8 位 1 字节 → 得到长度前缀 + flag。

四、逐步过程（核心）

4.1 取回附件（两种途径）

途径一（本机直连）：

curl -s http://127.0.0.1:<端口>/bundle.tar -o bundle.tar

途径二（沙箱 / 无法直连，用 wss 隧道）：见第五章 5.1 代码。

4.2 第 1 层：bundle.tar

$ file bundle.tar
bundle.tar: POSIX tar archive
$ tar -tvf bundle.tar # 先”只看不解”，-t 列内容
-rw-r–r– 0/0 362 bag.zip

tar 里就一个 bag.zip，解出来：tar -xf bundle.tar

4.3 第 2 层：bag.zip

$ file bag.zip
bag.zip: Zip archive data …
$ unzip -o bag.zip
$ ls
bag.zip noise.txt shot.png

4.4 看看解出来的东西

$ cat noise.txt
nothing # 只有 “nothing”，诱饵
$ file shot.png
shot.png: PNG image data, 32 x 7, 8-bit/color RGB, non-interlaced

“最里面是一张图” → 就是 shot.png（32 宽 7 高）。

4.5 手算 PNG 头（看清尺寸）

字节位置 内容 含义
0~7 89 50 4E 47 0D 0A 1A 0A PNG 签名
8~11 00 00 00 0D IHDR 长度 13
12~15 49 48 44 52 “IHDR”
16~19 00 00 00 20 宽度 = 32
20~23 00 00 00 07 高度 = 7
24 08 位深 8
25 02 颜色类型 2（真彩色 RGB）

像素总数 = 32 × 7 = 224 个
每个像素可藏 1 位 → 共 224 位 = 28 字节

4.6 观察像素：R 通道是比特

用程序统计各通道取值：

R 通道取值集合: {128, 129} <– 只差最低位！
G 通道取值集合: {32}
B 通道取值集合: {32}
R=128 -> 二进制 …0000 最低位 0
R=129 -> 二进制 …0001 最低位 1

4.7 提取比特并拼成文字

取 R 通道最低位，从上到下、从左到右，每 8 位拼成 1 字节：

位流结果 : \x00\x00\x00\x16 flag{m80_c39a54494c64} \x00\x00
第 4 字节 : 0x16 = 22 -> 表示后面 flag 长 22 个字符

于是得到：

flag{m80_c39a54494c64}

最终 flag：flag{m80_c39a54494c64}

五、Python 代码逐行讲解

5.1 通过 wss 隧道取文件（fetch.py）

import ssl, websocket
URL = ‘wss://ctf.bi6pcr.com/api/proxy/01a0d8f6-967d-7d0c-966b-a069015ae7bd’

def http(path, save=None):
ws = websocket.create_connection(URL, timeout=25,
header=[‘Origin: https://ctf.bi6pcr.com'],
sslopt={‘cert_reqs’: ssl.CERT_NONE})
req = (‘GET %s HTTP/1.1\r\nHost: 127.0.0.1\r\n’
‘Accept: /\r\nConnection: close\r\n\r\n’ % path)
ws.send(req) # 通过隧道发出 HTTP 请求
buf = b’’
while True:
d = ws.recv() # 收到 HTTP 响应(头 + 内容)
if not d:
break
buf += d
ws.close()
if save:
open(save, ‘wb’).write(buf)
return buf

r = http(‘/bundle.tar’, save=’raw.bin’)
head, _, body = r.partition(b’\r\n\r\n’) # 按空行切掉 HTTP 响应头
open(‘bundle.tar’, ‘wb’).write(body) # 得到真正的 tar 文件

代码 作用 · 原理
import ssl, websocket ssl 用于关闭证书校验，websocket 提供 WebSocket 客户端
URL = … 平台给的代理隧道地址（转发到题目实例）
def http(path, save=None) 封装一个”发 HTTP 请求”的函数，可复用
websocket.create_connection(…) 建立 wss 连接；CERT_NONE 跳过证书校验
‘GET %s HTTP/1.1\r\n…’ % path 手写 HTTP 请求报文；\r\n 是行分隔，末尾空行表示请求头结束
ws.send(req) 通过隧道把请求发给目标服务器
ws.recv() 接收返回数据（响应头 + 文件内容）
if not d: break 收到空数据代表结束，跳出循环
r.partition(b”\r\n\r\n”) 按第一个空行切开：head 是响应头，body 是文件
open(“bundle.tar”,”wb”).write(body) 以二进制写入真正的 tar 文件

5.2 从图片里提取 flag（extract.py）

import re
from PIL import Image
im = Image.open(‘shot.png’).convert(‘RGB’) # 统一成 RGB
w, h = im.size # 32 x 7
px = im.load() # px[x,y] -> (R,G,B)
bits = []
for y in range(h): # 逐行
for x in range(w): # 逐列
bits.append(px[x, y][0] & 1) # 取 R(红)通道最低位 -> 0/1
text = ‘’
for i in range(0, len(bits) - 7, 8): # 每 8 位拼 1 字节
text += chr(int(‘’.join(map(str, bits[i:i + 8])), 2))
print(repr(text)) # 位流：\x00\x00\x00\x16 flag{…} \x00\x00
print(re.search(r’flag{[^}]*}‘, text).group()) # 正则抠出 flag

代码 作用 · 原理
Image.open(‘shot.png’) 打开 PNG
.convert(‘RGB’) 统一成 RGB，保证每像素是 (R,G,B)
w, h = im.size 取宽高（32、7）
px = im.load() 像素访问器，px[x,y] 返回该点颜色
px[x, y][0] 索引 0 = 红色 R 通道的值
& 1 只保留最低位 → 得到藏进去的那个比特
for i in range(0, len(bits)-7, 8) 每 8 位一组（-7 防止末尾不足 8 位）
int(‘’.join(map(str, bits[i:i+8])), 2) 把 ‘0’/‘1’ 字符串按二进制转成整数
chr(…) 把整数转成字符
re.search(r’flag{[^}]*}‘, text) 正则匹配 flag{…}，把 flag 抠出来

六、在 Linux 上怎么跑（三种方式，含逐行讲解）

方式一 一键递归解包脚本（推荐）

#!/bin/bash

用法: bash unwrap.sh bundle.tar —— 反复识别并解压，直到没有压缩包

set -u
W=”unwrapped”; rm -rf “$W”; mkdir “$W”; cp “$1” “$W”/; cd “$W”
for i in $(seq 1 30); do
f=$(find . -type f ! -name ‘.done’ | sort | head -1)
[ -z “$f” ] && break
t=$(file -b “$f”)
echo “解 $f ($t)”
case “$t” in
gzip|bzip2|XZ)
cp “$f” “$f.bin”
{ gzip -dc “$f.bin” 2>/dev/null || bzip2 -dc “$f.bin” 2>/dev/null || xz -dc “$f.bin” 2>/dev/null; } > “${f}.out”
rm -f “$f.bin”;;
Zip) unzip -o -q “$f” -d “${f}.out”;;
“tar archive”) mkdir -p “${f}.out”; tar -xf “$f” -C “${f}.out”;;
7-zip|RAR) 7z x -y -o”${f}.out” “$f” >/dev/null;;
esac
mv “$f” “$f.done” # 标记已处理，配合 find 的 ! -name ‘.done’ 防止死循环
done
echo “=== 剩余文件(大概率就是那张图) ===”
find . -type f ! -name ‘*.done’

片段 作用
find . -type f ! -name “*.done” 找还没处理过的普通文件，排除已标记的
file -b “$f” 只看类型不看文件名，用 case 匹配
gzip -dc x | … > out -d 解压、-c 输出到屏幕；对没有后缀的 gz 也能用
unzip -o -q -o 覆盖、-q 安静
tar -xf … -C … -x 解包、-f 指定文件、-C 指定目录
mv “$f” “$f.done” 标记已处理，避免死循环

方式二 手动逐层命令（最直观，推荐新手）

tar -tvf bundle.tar # 1. 先看 tar 里有啥
tar -xf bundle.tar # 2. 解开
file bag.zip # 3. 看 zip
unzip bag.zip # 4. 解开 -> shot.png / noise.txt
file shot.png # 5. 确认是图片

方式三 binwalk 兜底（懒人法）

sudo apt install -y binwalk
binwalk -Me bundle.tar # -M 递归、-e 提取，自动扒出嵌套内容

之后对图片做隐写检测：

zsteg shot.png # PNG 位隐写专用（本题 R 通道 LSB 会被它直接报出来）
exiftool shot.png # 看元数据
strings shot.png # 看可打印字符串

七、易错点

现象 / 报错 原因 解决
里面文件没有后缀 只是被别人改了名 用 file 看真实类型
tar -xf 报错 文件不完整（被当网页存了） 确认下载的是二进制附件，不是 HTML
不知道该解哪层 嵌套顺序不定 每解一层就 file 一下，谁像压缩包解谁
图片打开正常却看不到 flag flag 藏在像素低位 别肉眼看，用 LSB 提取
提取出来是乱码 位序/通道选错 本题用 R 通道、高位在前、自上而下
以为 flag 在 noise.txt noise.txt 是诱饵(“nothing”) 回到图片继续找

八、速查卡

一句话思路：bundle.tar(tar) -> bag.zip(zip) -> shot.png(PNG) -> R通道LSB -> flag

解包三连

file 文件名 # 看类型
tar -xf / unzip -o / 7z x # 按类型解
cat / file / binwalk # 看结果，循环

图片 LSB 提取（Python 见 5.2）

R 通道取值 {128,129} => 最低位是比特

本题答案

flag{m80_c39a54494c64}
