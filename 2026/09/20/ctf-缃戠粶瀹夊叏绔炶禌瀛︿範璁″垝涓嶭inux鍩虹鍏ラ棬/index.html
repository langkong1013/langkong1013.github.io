网络安全竞赛备战指南

langkong10132026-09-202026-10-28

—— 御网杯学习计划表 & Linux 基础入门（两天速成）

适用对象：大一 · 网络空间安全专业新生

目标：大一学年参加御网杯，取得二等奖及以上

编制日期：2026 年 9 月

第一章 认识御网杯与你的参赛目标

1.1 御网杯是什么

“御网杯”网络安全大赛是由河南省教育厅与中共河南省委网络安全和信息化委员会办公室联合主办的省级高水平网络安全专项赛事，面向全国普通高校在校师生，是网安专业学生公认的“练兵场”。大赛通常在每年 4—12 月举办，分为线上挑战赛、线下精英赛、校际联赛三个赛段。

1.2 赛制与考点

  • 赛段一 · 线上挑战赛：采取解题挑战（CTF 夺旗）模式，分“网络安全赛”“数据安全赛”两个方向，各赛 1 天。
  • 赛段二 · 线下精英赛：采取现场实战竞赛模式（网络与安全运维、应急响应、安全防御、靶场渗透实战），由线上赛成绩优秀的队伍晋级。
  • 赛段三 · 校际联赛：以学校为单位参赛，按年度积分排名。

线上挑战赛的核心题型（也就是你现阶段要重点准备的）：

  • NISP 理论题——网络安全基础知识选择题；
  • 基础类 / 网站技术类（Web）——SQL 注入、文件上传、命令执行等；
  • 密码学类——古典密码、编码转换、RSA 等；
  • 逆向工程类、漏洞挖掘类、系统安全类（Linux）、智能终端类、综合类（杂项 Misc）。

1.3 关键时间线（以第十届为参照）

你大一学年对应的是 2027 年举办的第十一届御网杯。以下时间点参考 2026 年第十届的安排，具体请以当年官方通知为准（官网：www.yuwangbei.cn，报名入口：bm.yuwangbei.cn）。

环节 参考时间 说明
官方通知发布 每年 4 月 关注官网与学院通知
注册报名 5 月上旬 — 5 月下旬 实名注册，3 人组队（队长 1 名 + 队员 2 名 + 指导教师）
线上挑战赛 5 月底（网络安全赛 / 数据安全赛各 1 天） 解题夺旗模式，一等奖 7%、二等奖 10%、三等奖 13%
线下精英赛报名 6 月中旬 — 6 月底 凭线上成绩择优晋级
线下精英赛 7 月 实战竞赛模式，在指定高校举行

1.4 你的目标拆解

“二等奖及以上”对应线上挑战赛前 17% 左右的参赛者。把它拆成可执行的小目标：

  1. 大一上学期结束前：能独立在 Linux 环境下操作、读懂并复现简单 Web 漏洞。
  2. 大一下学期（3 月）前：Misc、Web 基础、密码学入门三大模块达到“能独立解简单题”的水平。
  3. 赛前 1 个月：完成组队、刷透历年真题、进行整套模拟计时训练。
  4. 最终目标：线上挑战赛拿分进入前 17%，冲击二等奖及以上，争取晋级线下赛。

第二章 整体学习计划表

2.1 学习路径总览

遵循“先通用基础，后专项突破，再实战刷题”的顺序。对新手而言，最容易拿分的是 Misc（杂项）、Web 和密码学，务必先把这三块吃透，再考虑逆向和 Pwn。

计算机网络 + Linux + Python → Misc / Web / 密码学 → 系统安全 → 逆向 / Pwn → 实战刷题

2.2 分阶段计划表

阶段 时间 核心目标 主要学习内容 验收标准
① 环境与认知 9 月第 1 周 搭好环境、建立认知 安装 Kali 虚拟机；了解 CTF 五大方向；注册刷题平台 能熟练进入 Kali 命令行；说清 web/crypto/misc/reverse/pwn 分别考什么
② 基础夯实 9 月中 — 10 月底（约 6 周） 打通通用基础 Linux 命令、Python 进阶、计算机网络（HTTP/TCP-IP）、HTML 基础 能在 Linux 下独立操作文件与网络；读懂 HTTP 请求；能手写小脚本
③ 入门题型 11 月 — 12 月（约 8 周） 拿下易得分模块 Misc（编码/隐写/流量）、Web 基础（SQL 注入、XSS、文件上传）、古典密码 刷完 BUUCTF 新手区；能独立解简单 Misc/Web 题
④ 核心深入 1 月 — 3 月 主攻方向深化 Web 进阶（命令执行、文件包含、SSRF、PHP 反序列化）、密码学（RSA/AES）、系统安全（Linux 提权） 各方向能解中等难度题；开始写 WriteUp
⑤ 实战刷题 3 月 — 4 月 以赛代练 打线上小比赛、攻防世界/CTFHub 专项、固定组队训练 每周至少 2 场练习赛；团队配合成型
⑥ 冲刺参赛 4 月 — 5 月 报名 + 模考 + 复盘 报名御网杯、做历年真题、补 NISP 理论、漏洞复现 完成报名组队；模拟得分达到二等奖以上水平

2.3 每周时间安排建议

  • 工作日：每天 1—2 小时（建议固定时段，如晚自习后），以理论学习 + 命令练习为主。
  • 周末：每天 2—4 小时，集中刷题或啃一块硬骨头。
  • 合计约 10—12 小时/周，坚持 8 个月即可具备参赛能力。

关键原则：70% 时间动手实操，30% 时间看理论。只看教程不敲命令等于没学。

2.4 推荐资源与平台

  • 刷题平台：BUUCTF、CTFHub、攻防世界（xctf）、NSSCTF、CTFtime（找比赛）。
  • 本地靶场：DVWA、SQLi-Labs、Pikachu（练 Web 漏洞）。
  • 工具集：Kali Linux、Burp Suite（抓包改包）、Wireshark（流量分析）、StegSolve（图片隐写）、CyberChef（编码转换）。
  • 学习文档：CTF Wiki（ctf-wiki.org）、看雪论坛、FreeBuf、各大战队公开的 WriteUp。
  • Python 库：requests（HTTP 请求）、base64/hashlib（编码与哈希）、pycryptodome（密码学，后期）。

2.5 学习纪律与心态

  • 每道做过的题都要写 WriteUp（解题记录），这是提升最快的方式。
  • 遇卡壳先自己查（man、CTF Wiki、搜索引擎），实在不会再问，锻炼独立解决问题的能力。
  • 接受“做不出来”：比赛中学会跳过难题、优先拿分，比死磕一道题更重要。
  • 关注学院通知：御网杯以学校为单位报名，务必在报名期内完成注册组队。

第三章 Linux 基础操作 · 第 1 天

3.1 为什么要学 Linux

CTF 比赛中的服务器、靶机绝大多数是 Linux 系统；御网杯的“系统安全类”直接考 Linux；Kali 等渗透工具本身就是 Linux 发行版。命令行（终端）是你在 Linux 下的主要工作方式，必须熟练掌握。

3.2 环境准备（三选一）

  1. 虚拟机（推荐）：安装 VMware Workstation Player（个人免费），下载 Kali Linux 虚拟机镜像导入即可。分配内存 2—4 GB、磁盘 20 GB 以上。
  2. WSL2：Windows 用户可在“启用或关闭 Windows 功能”中开启 WSL，然后在应用商店安装 Ubuntu/Kali。
  3. 云服务器：租一台便宜的学生机，直接在浏览器里练习。

本教程所有命令在 Kali / Ubuntu / Debian 中通用。

3.3 认识终端与 Shell

终端（Terminal）是你与系统交互的窗口；Shell 是运行在终端里的命令解释器，最常用的是 bash。命令的一般格式如下：

命令 [选项] [参数] # 例如： ls -l /home

提示符的含义：

kali@kali:~$

用户名@主机名:当前目录 + 权限符号

$ 表示普通用户，# 表示 root（超级用户）

路径符号：. 表示当前目录，.. 表示上级目录，~ 表示当前用户的家目录，- 表示上一次所在目录。

3.4 文件系统结构

Linux 中“一切皆文件”，整个系统是一棵以 / （根目录）为起点的树。常用目录：

目录 含义
/ 根目录，所有文件的起点
/bin、/usr/bin 存放常用命令
/etc 系统配置文件
/home 普通用户的家目录（如 /home/kali）
/root root 用户的家目录
/tmp 临时文件目录
/var 经常变化的数据，日志在 /var/log
/dev 设备文件

3.5 目录与文件操作（最核心）

命令 作用 常用示例
pwd 显示当前所在路径 pwd
ls 列出目录内容 ls -l（详情） ls -a（含隐藏） ls -lh（易读大小）
cd 切换目录 cd /etc cd .. cd ~
mkdir 创建目录 mkdir -p a/b/c（递归创建）
rmdir 删除空目录 rmdir mydir
touch 创建空文件 touch test.txt
cp 复制 cp a.txt b.txt cp -r dir1 dir2（复制目录）
mv 移动 / 重命名 mv a.txt b.txt（重命名） mv a.txt /tmp/（移动）
rm 删除 rm a.txt rm -r dir（递归） rm -f（强制）
ln 创建链接 ln -s /path/target link

⚠️ 危险提示：rm -rf / 会删除整个系统，绝不要尝试。删除前务必确认路径。

3.6 查看文件内容

命令 作用
cat 文件 一次性输出整个文件
less 文件 分页查看（空格翻页，q 退出，/关键词 搜索）
head -n 5 文件 查看前 5 行（默认前 10 行）
tail -n 5 文件 查看后 5 行；tail -f 文件 实时跟踪
echo “内容” 输出文本，常用于写文件

3.7 获取帮助

man ls # 查看 ls 的完整手册，q 退出，/关键字 搜索
ls –help # 快速查看用法
apropos 关键词 # 搜索相关命令

3.8 终端快捷键（提速关键）

快捷键 作用
Tab 自动补全命令或路径（按两次列出所有可能）
Ctrl + C 中断当前正在运行的命令
Ctrl + D 结束输入 / 退出当前 Shell
Ctrl + L 清屏（等价于 clear）
Ctrl + U 删除光标前的整行内容
Ctrl + W 删除光标前的一个单词
Ctrl + A / Ctrl + E 光标跳到行首 / 行尾
↑ / ↓ 翻阅历史命令
Ctrl + R 反向搜索历史命令（输入关键字回车）
!! 重复执行上一条命令

3.9 权限基础

用 ls -l 查看文件时，每行开头形如 -rwxr-xr–：第 1 位是类型（- 普通文件，d 目录），后 9 位分三组，分别代表属主、属组、其他人的权限。

r = 读（4） w = 写（2） x = 执行（1）

修改权限用 chmod：

chmod 755 script.sh # 属主 rwx(7)、属组 r-x(5)、其他人 r-x(5)
chmod +x script.sh # 给所有用户加执行权限
chmod u+x,g-w file # 字母法：u属主 g属组 o其他人 a所有人

其他相关命令：

  • chown 用户:组 文件 —— 修改属主和属组；
  • sudo 命令 —— 以 root 权限执行命令（需要密码）；
  • su - 用户名 —— 切换到其他用户。

3.10 第 1 天命令速查

pwd ls cd mkdir rmdir touch cp mv rm ln
cat less head tail echo man
chmod chown sudo su

第四章 Linux 基础操作 · 第 2 天

4.1 文本处理常用命令

命令 作用 示例
grep 按关键字搜索文本 grep “flag” a.txt -i 忽略大小写 -n 显示行号 -r 递归
wc 统计行/词/字符数 wc -l a.txt（行数）
sort 排序 sort a.txt sort -n 数字排序 sort -r 倒序
uniq 去除相邻重复行 sort a.txt | uniq -c（统计出现次数）
cut 按列提取 cut -d ‘:’ -f1 /etc/passwd（以冒号分隔取第 1 列）
sed 流式替换（入门） sed ‘s/old/new/g’ a.txt（把 old 替换为 new）
awk 按列处理（入门） awk ‘{print $1}’ a.txt（输出第 1 列）

这几个命令在流量分析、日志分析和 CTF 信息提取中极其常用，务必掌握 grep、wc、sort、uniq、cut。

4.2 管道与重定向

管道 | 把前一个命令的输出，作为后一个命令的输入；重定向把输出写到文件。

ls -l | grep “.txt” # 管道：只显示 .txt 文件
echo “hello” > a.txt # > 覆盖写入（会清空原内容）
echo “world” >> a.txt # >> 追加写入
grep flag a.txt > result.txt
命令 2> error.txt # 把错误信息写入文件
命令 > all.txt 2>&1 # 标准输出和错误都写入

4.3 查找文件 find

find 是 CTF 里找 flag 的利器：

find / -name “flag*” 2>/dev/null # 全盘找文件名含 flag 的文件
find . -type f -name “*.txt” # 只找普通文件
find / -type d -name “web” # 找目录

4.4 压缩与解压

命令 作用
tar -czvf out.tar.gz 目录/ 打包并压缩为 .tar.gz
tar -xzvf in.tar.gz 解压 .tar.gz
tar -tzvf in.tar.gz 查看压缩包内容不解压
unzip a.zip 解压 zip 文件
zip -r out.zip 目录/ 把目录压缩为 zip
gzip / gunzip 压缩 / 解压单个文件

4.5 网络相关命令

命令 作用
ping -c 4 目标 测试连通性，发 4 个包
curl http://xxx 访问 URL；-I 看响应头，-O 下载文件
wget http://xxx/file 下载文件
ip a / ifconfig 查看本机 IP 地址
ss -tulnp / netstat -tulnp 查看端口监听情况
ssh user@host 远程登录另一台主机
nc -lvnp 4444 netcat 监听端口（CTF 反弹 Shell 常用）

4.6 进程管理

命令 作用
ps aux / ps -ef 查看所有进程
top / htop 实时查看进程与资源占用
kill PID 结束指定进程；kill -9 PID 强制结束
命令 & 让命令在后台运行
jobs / fg / bg 查看后台任务 / 调回前台 / 放后台

4.7 软件包管理（Kali / Ubuntu 用 apt）

sudo apt update # 更新软件源
sudo apt install 软件名 # 安装
sudo apt search 关键字 # 搜索
sudo apt remove 软件名 # 卸载

4.8 环境变量

echo $PATH # 查看 PATH，决定命令从哪里查找
echo $HOME # 家目录
echo $USER $SHELL # 当前用户 / 所用 Shell
export MYVAR=123 # 临时设置环境变量
which 命令 # 查看命令所在路径

4.9 文本编辑器入门

编辑器 基本操作
nano 直接编辑；Ctrl+O 保存，Ctrl+X 退出
vim i 进入插入模式，Esc 退出编辑，:wq 保存退出，:q! 不保存退出

Linux 是网络安全的地基，练到“肌肉记忆”后，后续学 Web、密码学、杂项都会顺畅很多。第 1 天的命令要反复敲，第 2 天的管道和文本处理在实战中会反复用到。

完成这两天的基础后，就可以进入计划表的“第 ③ 阶段：入门题型”，从 Misc 和简单 Web 题开始刷起。祝你在御网杯赛场上旗开得胜！
