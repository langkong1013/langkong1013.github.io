PHP 零基础速成（够做 Web 题）

langkong10132026-10-202026-10-28

只讲 8 个知识点 + 10 个小例子 + 3 道练习，学完能读懂 CTF 里的 PHP 源码

适用：完全没学过 PHP，但要做 Web 题的人

一、PHP 是什么，怎么运行

PHP 是一种服务器端脚本语言。你把 .php 文件放到网站目录里，用户访问时：

  1. 服务器读这个文件
  2. 执行 里面的代码
  3. 把执行结果（HTML）发给浏览器

关键：用户看到的是执行结果，不是代码。除非代码里主动打印源码（比如 highlight_file）。

1.1 最小例子

  • —— 这是 PHP 代码块，只有这里面的内容会被执行
  • echo —— 输出，相当于 Python 的 print
  • 分号 ; —— 每条语句结束必须加分号（新手最容易漏）

1.2 本地怎么跑（可选）

Ubuntu 上装一个 PHP：

sudo apt install -y php-cli
php -v

  • sudo apt install -y php-cli —— 安装 PHP 命令行版本
  • php -v —— 看版本，有输出说明装好了

运行一个文件：

php test.php

或者起一个本地网站：

php -S 127.0.0.1:8000

  • -S —— 启动内置 web 服务器
  • 127.0.0.1:8000 —— 监听地址和端口
  • 然后在浏览器访问 http://127.0.0.1:8000/test.php

二、变量：以 $ 开头

  • $a —— PHP 的变量名必须带 $ 符号，这是和 Python 最大的区别
  • 不需要声明类型，直接赋值就行（弱类型）
  • true / false —— 布尔值，注意不加引号

2.1 超全局变量（做 Web 题最重要）

PHP 有几个”自带变量”，专门用来接收用户输入：

变量 来源 例子
$_GET URL 问号后面的参数 ?name=gjz → $_GET[“name”]
$_POST POST 请求体里的参数 表单提交
$_REQUEST GET + POST + Cookie 都能收 最宽松，也最危险
$_COOKIE 浏览器带来的 Cookie $_COOKIE[“role”]
$_SERVER 服务器信息 $_SERVER[“REMOTE_ADDR”]

例子：访问 http://x.com/a.php?name=gjz

安全意义：只要代码用了这些变量，用户就能控制它的值。这就是所有 Web 漏洞的起点。

三、字符串与拼接

3.1 两种引号

结论：双引号会替换变量，单引号不会。

3.2 拼接用点号 .

  • . —— 字符串拼接，相当于 Python 的 +
  • 注意：PHP 里 + 只做数学加法，拼接必须用 .

四、数组

"gjz", "age" => 18]; // 关联数组（键 => 值） echo $map["name"]; // 输出 gjz ?>
  • [“a”,”b”] —— 方括号定义数组
  • 下标从 0 开始
  • “键” => “值” —— => 是”映射到”，左边是键，右边是值

4.1 遍历数组

  • foreach ($arr as $v) —— 把数组里每个值依次赋给 $v
  • 相当于 Python 的 for v in arr

五、函数

  • function 函数名(参数) { … } —— 定义函数
  • return —— 返回结果
  • 调用时写 函数名(参数)

5.1 引用传递 &（看懂即可）

  • &$v —— 参数前加 &，表示”引用传递”
  • 普通传参是”复制一份”，引用传递是”直接改原来那个变量”
  • 做题时看到 & 不用慌，知道”函数里改了会影响外面”就行

六、条件判断

= 18) { echo "adult"; } else { echo "minor"; } ?>

常用运算符：

符号 含义 例子
== 等于（弱比较，只比值） “1” == 1 为 true
=== 全等（类型和值都相同） “1” === 1 为 false
!= 不等于 $a != $b
> >= < <= 大小比较 $age >= 18
&& 并且 A && B
|| 或者 A || B
! 取反 !isset($x)

⚠️ 安全题常考：== 是弱比较，”0” == false 为 true，”1e3” == “1000” 也为 true。很多绕过就靠这个。

七、必须记住的 6 个字符串函数

函数 作用 例子 结果
strlen($s) 字符串长度 strlen(“abc”) 3
strpos($s, $x) 找 $x 第一次出现的位置 strpos(“a?b”, “?”) 1
substr($s, $start, $len) 截取子串 substr(“abcdef”, 0, 3) abc
mb_strpos / mb_substr 同上，但支持中文（多字节） mb_substr(“你好世界”, 0, 2) 你好
urldecode($s) URL 解码 urldecode(“a%2eb”) a.b
str_replace($a,$b,$s) 替换 str_replace(“a”,”b”,”aa”) bb

位置从 0 开始数。strpos 找不到时返回 false。

7.1 用它们做”截断”（LFI 题的核心）

  • $page . “?” —— 先拼一个问号，保证一定能找到
  • strpos(…) —— 返回问号的下标（从 0 数）
  • substr($page, 0, $pos) —— 从 0 取到 $pos（不含），得到问号前的部分

八、include：文件包含

  • include —— 把另一个文件”搬进来”，当作当前文件的一部分执行
  • require —— 类似，但文件不存在时会直接报错终止（include 只警告）
  • include_once / require_once —— 只包含一次

为什么危险：

如果 include 后面的文件名是用户能控制的（比如 $_GET[“file”]），用户就能让服务器包含任意文件——这就是”文件包含漏洞（LFI）”。

九、类与 static（只学到”能读懂”）

那道 LFI 题里有 class 和 static，很多新手卡在这。其实只需要看懂这一点：

  • class Tool —— 定义一个”工具箱”
  • function hello —— 工具箱里的一个工具
  • static —— 表示”不用创建对象就能直接用”
  • Tool::hello() —— 用 类名::函数名() 的方式调用

做题时看到 emmm::checkFile($x)，意思就是”调用 emmm 这个工具箱里的 checkFile 函数”。知道这个就够了。

十、用这些知识读懂那道 LFI 题

现在回头看核心三行：

$whitelist = [“source”=>”source.php”, “hint”=>”hint.php”];
if (in_array($page, $whitelist)) return true;
$_page = mb_substr($page, 0, mb_strpos($page . ‘?’, ‘?’));
if (in_array($_page, $whitelist)) return true;
…
include $_REQUEST[“file”];

逐行翻译：

代码 人话
$whitelist = […] 白名单只有 source.php 和 hint.php
in_array($page, $whitelist) 整个参数完全等于白名单才放行
mb_strpos($page . “?”, “?”) 找第一个问号的位置
mb_substr($page, 0, 位置) 只取问号前面那一截
in_array($_page, $whitelist) 这一截在白名单里就放行
include $_REQUEST[“file”] 把完整的 file 值当文件包含进来

于是：

?file=source.php?/../../../../ffffllllaaaagggg

  • 校验：截断后是 source.php → 在名单里 → 通过
  • 执行：include 整串 → ../ 穿越目录 → 读到目标文件

一句话：检查的和使用的，不是同一个值。

十三、新手最容易踩的 6 个坑

坑 现象 原因 / 解决
漏分号 Parse error 每条语句结尾必须 ;
用 + 拼字符串 结果变成 0 或报错 拼接要用 .
单引号里写变量 原样输出 $name 双引号才会解析变量
$_GET 取不到 报 undefined index 参数名拼错，或用了 POST 却读 GET
== 和 === 混用 判断结果意外为 true == 是弱比较，”0” == false
include 路径不对 文件找不到 相对路径是相对于当前执行文件

十四、学完之后怎么练

  1. 把上面 10 个例子亲手敲一遍，确保能跑出结果。
  2. 做 3 道小练习，不看答案。
  3. 回去重看那道 LFI 题，尝试自己讲一遍”为什么能绕过”。
  4. 去 CTF² 找 2 道 PHP 源码题（源码泄露 / 文件包含）练手。

判断标准：能不看资料，写出”接收参数 → 判断 → 输出”的小脚本，就算过关。
